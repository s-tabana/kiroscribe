# DAT: データの保存と引き継ぎ

データの保存場所と、以前の名前（Kiroku）のアプリからの引き継ぎ。

- **DAT-001** ［単体・E2E］ ノート・文字起こし・議事録・チャット・設定は、アプリのデータフォルダ（Windows では `%APPDATA%\dev.kiroscribe.desktop`）の `kiroscribe.db` に保存する。フォルダがなければ作る。
- **DAT-002** ［単体］ データベースの形（スキーマ）は、起動のたびに確かめ、まだ適用していない変更だけを順に適用する。新しい版で開いても、それまでのデータは残る。
- **DAT-003** ［単体］ 存在しないノートに対する文字起こし・チャットは保存されない。
- **DAT-004** ［単体・結合］ 以前の名前のアプリ（Kiroku。データフォルダ `dev.kiroku.desktop`、ファイル `kiroku.db`）のデータは、Kiroscribe のデータベースがまだない最初の起動のときに、新しい場所へコピーして引き継ぐ（ノート・文字起こし・議事録・チャット・設定）。以前のアプリのファイルは消さない。
- **DAT-005** ［単体］ Kiroscribe のデータベースがすでにあるときは、以前のデータで上書きしない。以前のデータがないときは、何もしない。
- **DAT-006** ［単体］ 以前のアプリが起動したまま（データベースを開いたまま）でも、直前までの変更を含めて引き継げる。引き継いだあとに Kiroscribe で行った変更は、以前のアプリのデータには影響しない。
- **DAT-007** ［単体・結合・E2E］ 引き継ぎのコピーに失敗したときは、中途半端なファイルを残さず、空のデータベースでは始めない（起動を止める）。次の起動でやり直せる。起動時の失敗（引き継ぎの失敗、データベースを開けない、など）は、「Kiroscribe を起動できませんでした。」に続けて理由と「データは変更していません。原因を取り除いてから、もう一度起動してください。」を書いたダイアログを出し、閉じられたら終了する。その間、メインウィンドウは出さない。
- **DAT-008** ［単体・結合］ 以前のアプリで保存した API キーは、最初の起動のときに、Kiroscribe にまだないものだけを引き継ぐ。Kiroscribe にすでにあるキーは上書きしない。以前のアプリのキーは消さない。
- **DAT-009** ［結合］ API キーの引き継ぎは、最初の起動の 1 回だけ行う（Kiroscribe で消したキーが、次の起動で以前のアプリから戻ることはない）。引き継ぎに失敗しても、アプリは起動する。
