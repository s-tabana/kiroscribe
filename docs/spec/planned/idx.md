# IDX: 資料の索引

会議の相棒（[cmp.md](cmp.md)）が探す、PC の中の資料と、その索引。段階1 は指定したフォルダと Kiroscribe の過去のノート、段階2 はブラウザの履歴とブックマーク。この節の未決の点は、末尾の「未決の点」にある。

## 指定したフォルダ（段階1）

- **IDX-001** ［単体・E2E］ 設定の「会議の相棒」の欄の「探すフォルダ」に、「フォルダを追加…」でフォルダを足せる。フォルダを選ぶダイアログは本体が開く。足す前に、確認のダイアログで、そのフォルダの資料の題名・場所（フォルダの名前と、そこからの相対のパス）・抜粋が、相棒が資料を選ぶときに Anthropic へ送られることを示し、OK のときだけ足す。一覧の各行に、パス・索引に入っているファイルの件数・「外す」を表示する。初期値は空。追加と外すは、その場で保存する（「設定を保存」を押さなくてよい）。
- **IDX-002** ［単体］ 追加したフォルダの中（下のフォルダを含む）の、扱う種類（IDX-004）のファイルを索引に入れる。隠しフォルダ、システムのフォルダ、名前が「.」で始まるフォルダ、`node_modules`、ごみ箱は除く。隠し属性・システム属性のファイル、名前が「.」で始まるファイル、Office の一時ファイル（名前が「~$」で始まるもの）も除く。
- **IDX-027** ［単体］ シンボリックリンク、ジャンクション、ショートカット（.lnk）はたどらない。追加したフォルダの外にあるファイルは、索引に入れない。
- **IDX-003** ［単体］ 索引に入れるのは、1 つのフォルダにつき 20,000 ファイルまで、1 ファイルにつき 50MB まで、1 ファイルから読む文字は先頭の 200,000 文字まで。20,000 ファイルを超えたフォルダは、一覧に「一部だけ索引に入れています（20,000 件まで）」と表示する。
- **IDX-004** ［単体］ 中身を読む種類は、テキスト（.txt・.md・.csv・.tsv）、Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）、PDF（文字を含むもの）、HTML（.html・.htm）。名前だけで探す種類は、.doc・.xls・.ppt・.rtf・.zip・.png・.jpg・.jpeg。それ以外の種類（実行ファイル・スクリプトなど）は、索引に入れない。
- **IDX-005** ［単体］ テキストの文字コードは、UTF-8（BOM の有無を問わない）、UTF-16（BOM 付き）、Shift_JIS を見分けて読む。文字を取り出せない PDF（画像だけのもの）、壊れたファイル、パスワード付きのファイルは、名前だけで探す。
- **IDX-006** ［単体］ 資料の題名は、文書の中の題名（Word の最初の見出し、PowerPoint の 1 枚目のタイトル、PDF の文書のプロパティの題名、HTML の title 要素）が 60 文字以内であればそれにし、なければ拡張子を除いたファイル名にする。
- **IDX-007** ［単体］ ファイルは読むだけで、書き換えない。
- **IDX-031** ［単体］ ローカルのフォルダの資料は、探し先の名前を「ローカルのフォルダ」、場所をファイルのパスにする。コピーのボタンは「パスをコピー」（ファイルのパスを書き込む）、開くボタンは「ファイルを開く」（既定のアプリで開く。CMP-032）にする。

## 索引の作り方と更新

- **IDX-008** ［単体・結合］ 索引は、相棒がオンのときだけ作る。アプリの起動時・相棒をオンにしたとき・フォルダを足したときに作り始め、裏で進める（画面の操作と録音を止めない）。設定の欄に、索引の状態（「索引を作っています（1,234 / 5,000 件）」「索引に入っています: 5,000 件（11:20 に更新）」）を表示する。
- **IDX-009** ［単体・結合］ 索引を作ったあとは、フォルダの変更を見張り、足された・変わった・消えたファイルを 1 分以内に索引へ反映する。見張れないフォルダ（ネットワークのドライブなど）は、30 分ごとに見直す。更新日時と大きさが変わっていないファイルは、読み直さない。
- **IDX-010** ［単体］ フォルダを外すと、そのフォルダのファイルを索引から消す。追加したフォルダが見つからないとき（ドライブが外れているなど）は、索引を消さずに残し、一覧に「見つかりません」と表示する。
- **IDX-011** ［単体・E2E］ 「索引を作り直す」を押すと、索引を空にしてから、いまオンにしてある探し先の索引を作り直す。探すフォルダは、すべてのファイルを読み直す。Kiroscribe の過去のノートは、IDX-017 の条件を満たすときだけ、IDX-017 と同じ範囲で入れ直す。ブラウザの履歴とブックマークは、IDX-023 の条件を満たすときだけ読み直す。相棒がオフのときは、ボタンを押せない（IDX-008・IDX-028）。
- **IDX-012** ［単体］ 索引は、アプリのデータフォルダの `search-index.db` に保存する（ノートのデータベースとは別のファイル）。開けないとき（壊れているなど）は、作り直す。ノートのデータには影響しない。
- **IDX-028** ［単体・結合］ 相棒をオフにすると、索引の作成・見張り・読み直しを止め、索引の中身をすべて消す。探すフォルダの一覧と、探し先ごとのオンとオフは残す（次にオンにしたときに作り直す。IDX-008）。

## 探し方

- **IDX-013** ［単体］ 検索語のどれかを、題名・ファイル名・中身に含む資料を探す。日本語は語の区切りに頼らず、部分一致で探す（2 文字の語も探せる）。英字の大文字と小文字、全角と半角は区別しない。
- **IDX-014** ［単体］ 一致した検索語が多いもの、題名やファイル名に一致したもの、更新日時が新しいものを上にする。
- **IDX-015** ［単体］ 抜粋は、資料の中で一致した語が最も集まっている部分の前後で、600 文字までにする。名前だけで探した資料には、抜粋を付けない。

## Kiroscribe の過去のノート（段階1）

- **IDX-016** ［単体・E2E］ 設定の「会議の相棒」の欄の「Kiroscribe の過去のノート」がオンなら、ノートの題名・自分のメモ・議事録・文字起こしから探す。録音中のノートは除く。初期値はオン。相棒がオンのときにオフからオンにするときは、確認のダイアログで、ノートの題名・作成日時と抜粋が、相棒が資料を選ぶ際に Anthropic へ送られることを示し、OK を押した場合だけオンにする。相棒がオフのときは、ダイアログを出さずに切り替え、送ることは相棒をオンにするときの確認（CMP-036）で示す。オンとオフは、ほかの設定と同じく「設定を保存」で保存する（SET-002）。ダイアログで OK を押しても、保存せずに閉じたときはオフのままにし、ノートの索引は作らない。オフにすると、ノートの索引の更新を止め、ノートの索引を消す。
- **IDX-017** ［単体］ ノートの索引は、保存した設定で、相棒と「Kiroscribe の過去のノート」（IDX-016）の両方がオンのときだけ作り、更新する。設定の保存で両方がオンになった時点（両方がオンのままアプリを起動した時点を含む）で、録音中のノートを除くすべてのノートを、IDX-016 の範囲（題名・自分のメモ・議事録・文字起こし）で索引に入れ直す。その後は、ノート・議事録・文字起こしが保存されるたびに更新し、ノートを削除したら消す。録音中のノートは、録音が終わってから索引に入れる。どちらかをオフにすると、更新を止め、ノートの索引を消す（相棒のオフは IDX-028）。
- **IDX-018** ［単体］ 時期の手がかり（CMP-006）が「前回」なら、録音中のノートより前に作ったノートを新しい順に上げ、題名が録音中のノートの題名に似ているもの（MIN-012 と同じ 2 文字ずつの重なりで 0.5 以上）をさらに上にする。「先週」「先月」なら、その期間（月曜から始まる前の週、前の月）に作ったノートを上にする。
- **IDX-019** ［単体］ 過去のノートの抜粋には、一致した部分の種類（「メモ」「議事録」「文字起こし」）を添える。
- **IDX-032** ［単体］ 過去のノートの資料は、探し先の名前を「Kiroscribe の過去のノート」、場所を「ノート「<題名>」 <作成日時>」（作成日時は NOTE-012 の形）にする。コピーのボタンは「要点をコピー」（該当する箇所と「（ノート「<題名>」 <作成日時>）」を書き込む）、開くボタンは「ノートを開く」（そのノートを開く。録音は止めない）にする。

## ブラウザの履歴とブックマーク（段階2）

- **IDX-020** ［単体・E2E］ 設定の「ブラウザの履歴とブックマーク（Chrome・Edge）」がオンなら、選んだプロファイル（IDX-029）の履歴とブックマークから探す。初期値はオフ。相棒がオンのときにオンにするときは、確認のダイアログで、ページの題名と送るための URL（クエリとフラグメントを除いたもの。CMP-043）が選択のときに Anthropic へ送られ、ブックマークのフォルダの名前は送られないことを示し、OK のときだけオンにする。相棒がオフのときは、ダイアログを出さずに切り替え、送ることは相棒をオンにするときの確認（CMP-036）で示す。オンとオフとプロファイルの選択（IDX-029）は、ほかの設定と同じく「設定を保存」で保存する（SET-002）。ダイアログで OK を押しても、保存せずに閉じたときはオフのままにし、履歴とブックマークは読まない。読み始める時点は IDX-023 で決める。
- **IDX-029** ［単体・E2E］ ブラウザの欄に、見つけた Chrome と Edge のプロファイル（ブラウザの名前とプロファイルの表示名）を一覧にし、探すプロファイルをチェックで選べる。初期値は、どのプロファイルも選ばない。
- **IDX-021** ［単体・結合］ 履歴は、ブラウザのファイル（Chrome は `%LOCALAPPDATA%\Google\Chrome\User Data\<プロファイル>\History`、Edge は `%LOCALAPPDATA%\Microsoft\Edge\User Data\<プロファイル>\History`）を、付随するファイルと一緒に一時フォルダへ写してから読み、読み終えたら写しを消す。ブラウザが起動したままでも読め、ブラウザのファイルは変えない。ブックマークは、同じプロファイルの `Bookmarks` を読む。
- **IDX-022** ［単体］ 索引に入れるのは、`http://`・`https://` のページの題名・URL・最後に見た日時・見た回数と、ブックマークの名前・URL・フォルダの名前だけ。URL のフラグメント（「#」から後ろ）は除いて入れる。直近の 180 日に見ていない履歴と、検索サイトの結果のページは入れない。ユーザー名やパスワードを含む URL と、クエリかフラグメントに認証の値の名前（`code`・`token`・`access_token`・`id_token`・`refresh_token`・`auth`・`key`・`api_key`・`apikey`・`password`・`passwd`・`pwd`・`secret`・`client_secret`・`session`・`sessionid`・`sid`・`sig`・`signature`・`X-Amz-Credential`・`X-Amz-Signature`・`X-Goog-Credential`・`X-Goog-Signature`。大文字と小文字は区別しない）を含む URL も入れない。
- **IDX-023** ［単体・結合］ 履歴とブックマークを読むのは、保存した設定で、相棒（CMP-036）とブラウザ（IDX-020）の両方がオンで、プロファイルを 1 つ以上選んでいる（IDX-029）ときだけ。この条件を満たすあいだ、次の時点で読み直す: 条件を満たしたままアプリを起動した時点、設定の保存で条件を満たした時点（相棒をオンにした、ブラウザをオンにした、初めてプロファイルを選んだ）、プロファイルの選択を足して保存した時点、録音を始めた時点、録音中の 10 分ごと、「索引を作り直す」を押した時点（IDX-011）。条件を満たさないときは、どの時点でも読まない。相棒がオフなら、アプリを起動しても、ブラウザやプロファイルの設定を変えても、録音を始めても、録音中の 10 分ごとの時点でも、「索引を作り直す」でも読まない。確認のダイアログ（CMP-036・IDX-020）で OK を押した時点では読まず、設定を保存した時点から読む（SET-002）。読み直しは裏で進め、画面の操作と録音を止めない。
- **IDX-024** ［単体］ ブラウザの資料の抜粋は、題名と URL（ブックマークならフォルダの名前も）にする。ページの本文は読まない。選択（CMP-013）で Anthropic へ送る抜粋は、題名と、クエリとフラグメントを除いた URL（CMP-043）だけにし、ブックマークのフォルダの名前は送らない。
- **IDX-025** ［単体］ Chrome・Edge が入っていないときや、ファイルを読めないときは、そのブラウザを飛ばし、設定の欄に理由を表示する。相棒のほかの探し先は動く。
- **IDX-030** ［単体・結合］ ブラウザをオフにすると、履歴とブックマークの読み直しを止め、索引からブラウザの資料をすべて消す。プロファイルの選択を外したときは、そのプロファイルの資料を消す。
- **IDX-033** ［単体］ ブラウザの資料は、探し先の名前を「ブラウザ（<ホスト名>）」、場所をページの URL にする。コピーのボタンは「URL をコピー」（URL を書き込む）にする。
- **IDX-026** ［単体・結合］ ブラウザの資料の開くボタンは「ブラウザで開く」にし、いまも索引にある URL だけを既定のブラウザで開く。`http://` の URL も開く（SEC-008 の条件のうち、`https://` に限る条件だけを外し、ほかの条件はそのまま当てはめる）。ほかの条件に当たる URL は開かず、「このリンクは開けません」と表示する。索引にない URL（ブラウザをオフにした、プロファイルの選択を外した、直近の 180 日に見ていないため索引から外れたなど）は開かず、「このページは、ブラウザの履歴とブックマークの索引にありません」と表示する。バッジと詳細は、保存した結果のまま表示する。

## 未決の点

### 未決 5: ブラウザで見たページの本文を読むか

決めること: 段階2 で、見つけたページの本文を取りに行くか。
本文がないと、該当する箇所は題名と URL だけになる。
推奨案で書いている項目: IDX-024。

| 案 | 変わること |
| --- | --- |
| A. 読まない。題名・URL・ブックマークのフォルダだけで探す（推奨） | 外部への接続は増えない（SEC-005 は変わらない）。題名に出ない内容では見つからない |
| B. 候補のページの本文を、その場で取りに行く | 中身で選べる。任意のサイトへ接続することになり、ログインが要る社内のページは読めない |

### 未決 6: http:// のページを開くか

決めること: 履歴とブックマークにある `http://` のページを、「ブラウザで開く」で開くか。
社内の Wiki などは `http://` のことがあり、いまの約束（SEC-008）では開けない。
推奨案で書いている項目: IDX-026（B にしたときは、`http://` の URL を開かず、「http:// のページは開けません。『URL をコピー』でブラウザに貼ってください」と表示する）。

| 案 | 変わること |
| --- | --- |
| A. 履歴とブックマークにある URL に限り、`http://` も開く（推奨） | 社内のページもすぐ開ける。開く URL は利用者のブラウザが以前に開いたものだけに限る。PR 2-2 で SEC-008 に例外を足す |
| B. `https://` だけを開き、`http://` はコピーだけにする | SEC-008 は変わらない。`http://` のページは、コピーしてブラウザに貼る手間がある |
