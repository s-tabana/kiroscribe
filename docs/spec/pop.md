# POP: ポップアップ

会議を検出したとき、長い録音で会議が終わったかを聞くときに、画面の右下に出す小さなウィンドウ。

- **POP-001** ［単体・E2E・手動］ ポップアップは、主モニターの右下に、幅 380px・高さ 128px、枠なし、常に手前、タスクバーには出さない形で表示する。位置は、見えている部分が、モニターの右端から 16px、下端から 64px 内側になるようにする（Windows のウィンドウの見えない枠は数えない。表示の拡大率が 125%・150% でも、見た目の位置は同じ）。表示するときに、ほかのウィンドウからフォーカスを奪わない。
- **POP-002** ［単体・E2E］ ポップアップがすでに出ているときに次の知らせが来たら、新しいウィンドウは出さず、表示の内容だけを入れ替える。ポップアップを開いた時点の最新の内容を表示する。
- **POP-003** ［単体］ 録音を始めたときは、会議の名前、「自動で録音・文字起こしを始めました」、経過時間（そのノートを録音している間）、「ノートを開く」「停止」を表示する。
- **POP-004** ［単体・E2E］ ポップアップの「停止」を押すと録音を止め、仕上げの間は「録音を停止しました。文字起こしを仕上げています…」、終わると停止の表示（POP-005）に変わる。会議が終わって自動で止まるときの仕上げの間は、「会議が終わりました。文字起こしを仕上げています…」と表示する。
- **POP-005** ［単体］ 録音を止めたあとは、「録音を停止しました。「<ノートのタイトル>」に保存しています。」と「ノートを開く」「議事録を作成」を表示する。この表示は 30 秒たつと自動で閉じる。
- **POP-006** ［単体］ 自動で録音できなかったとき、または自動で始めた録音が API キーの誤りで止まったとき（TRN-014）は、理由と「設定を開く」を表示する。
- **POP-007** ［単体・E2E］ 「ノートを開く」を押すと、メインウィンドウを表示して手前に出し、そのノートを開き（検索欄は空に戻す）、ポップアップを閉じる。
- **POP-008** ［単体・E2E］ 「議事録を作成」を押すと、POP-007 と同じようにノートを開き、議事録の作成を始める（MIN-018）。
- **POP-009** ［単体・E2E］ 「設定を開く」を押すと、メインウィンドウを表示して設定画面を開き、ポップアップを閉じる。
- **POP-010** ［単体］ ポップアップの ×（閉じる）は、ポップアップを閉じるだけで、録音は続く。
- **POP-011** ［単体・結合］ 録音中の表示とエラーの表示は、利用者が閉じるか、次の知らせで入れ替わるまで出たままになる（自動では閉じない）。自動で始めた録音をメインウィンドウの「停止」で止めたときは、ポップアップも停止の表示（POP-005）に変わる（ポップアップを閉じていたときは、出し直さない）。ポップアップの「停止」が止めるのは、そのポップアップが知らせている録音だけで、その録音がもう終わっていたら、停止の表示に変えるだけにする。
- **POP-012** ［E2E］ ポップアップは、上部をドラッグして移動できる。
- **POP-013** ［単体］ ポップアップには、アプリの更新の知らせを出さない。
- **POP-014** ［単体・結合］ 長い録音で会議が終わったかを聞くとき（REC-024）は、「会議は終わりましたか？」と、答えがなければ止めるまでの残り時間（「1:58 後に止めて保存します」）、「続ける」「止める」を表示する。上部には、自動で始めた録音なら会議の名前、手動で始めた録音なら「Kiroscribe」を出す。「続ける」を選ぶと、自動で始めた録音なら録音中の表示（POP-003）に戻し、手動で始めた録音ならポップアップを閉じる。この表示は、答えるか録音が止まるまで出たままにする（× で閉じても、答えがなければ REC-026 のとおり止める）。答える前に、その録音をメインウィンドウやトレイで止めたときは、仕上げの間は仕上げ中の表示（POP-004）、保存が終わってから停止の表示（POP-005）に変える。もう出していない確認への答え（答えがなく止めたあと・取り下げたあと・同じノートで録音し直したあとに届いた答え）は、録音に触れない。確認を取り下げたとき（REC-026）、× で閉じていたポップアップは出し直さない。
- **POP-015** ［単体・結合］ 確認に答えがなく録音を止めたとき（REC-026）は、仕上げの間は「会議が終わりました。文字起こしを仕上げています…」、終わると「答えがなかったため、録音を停止しました。「<ノートのタイトル>」に保存しています。」（タイトルが空なら「無題のノート」）と「ノートを開く」「議事録を作成」を表示する。この表示は、自動では閉じない。この知らせは、利用者の遅れた答えで上書きしない。
