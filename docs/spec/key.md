# KEY: API キー

OpenAI・Anthropic の API キーの入力・保存・削除。漏らさないための約束は「セキュリティ上の約束」の節。

- **KEY-001** ［単体・結合］ API キーの欄にキーを入れて「保存」を押すと、前後の空白を除いて保存し、入力欄を空にして、「設定済み」の表示と「<名前> のキーを保存しました」を出す。「設定を保存」を押さなくても、その場で保存される。
- **KEY-002** ［単体］ 「削除」（設定済みのときだけ表示）を押すとキーを消し、「未設定」の表示に戻る。空のキーを保存した場合も削除になる。保存されていないキーを削除してもエラーにならない。
- **KEY-003** ［単体］ 設定済みのキーがあるときに新しいキーを保存すると、新しいキーで置き換わる。入力欄が空（空白だけ）のときは「保存」を押せない。
- **KEY-004** ［結合］ Windows では、キーを Windows 資格情報マネージャーに、サインインし直しても残る汎用資格情報として保存する（名前は「openai-api-key.Kiroscribe」「anthropic-api-key.Kiroscribe」）。アプリを起動し直しても読め、削除すると資格情報マネージャーからも消える。設定画面に保存先（「Windows 資格情報マネージャー」）を表示する。
- **KEY-005** ［単体］ Windows 以外（開発用）では、キーをアプリのデータフォルダの secrets.json に、本人だけが読み書きできる権限（0600）で保存する。
- **KEY-006** ［結合・E2E］ 保存したキーは、アプリを起動し直さなくても、次の録音・議事録の作成・AI チャットから使われる。アプリを起動し直しても残っている。
- **KEY-007** ［単体］ Windows 資格情報マネージャーを読み書きできなかったときは、「資格情報ストアのエラー: 理由」のエラーになる。キーの保存・削除に失敗したときは、設定画面の下部に理由を表示する。
- **KEY-008** ［単体］ キーの値は `"openai"` と `"anthropic"` の名前で区別して保存・削除する（OpenAI のキーの操作が Anthropic のキーに影響しない）。
- **KEY-009** ［単体・E2E］ API キーの各欄に「キーを発行する」リンクがあり、押すと発行のページ（OpenAI は `https://platform.openai.com/api-keys`、Anthropic は `https://platform.claude.com/settings/keys`）を既定のブラウザで開く。アプリの画面は別のページに移らない。開けるのは `https://` の URL だけ（SEC-008）。開けなかったときは、設定画面の下部に理由を表示する。
