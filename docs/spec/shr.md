# SHR: 共有

議事録・メモ・文字起こしを Markdown でコピー・保存する。

- **SHR-001** ［単体］ 「共有」を開くと、含める内容（議事録・自分のメモ・文字起こし）を選べる。開くたびに、議事録があれば議事録だけ、なければ自分のメモだけが選ばれた状態になる（文字起こしは選ばれていない）。ノートにないものは選べず、議事録がないときは「まだ作成していません」と表示する。
- **SHR-002** ［単体］ 何も選ばれていないときは、「Markdown をコピー」「ファイルに保存…」を押せない。
- **SHR-003** ［単体］ 共有のメニューは、Esc を押すか、メニューの外を押すと閉じる。
- **SHR-004** ［単体］ 書き出す Markdown は、「# タイトル」（空なら「無題のノート」）、作成日時（「2026年11月20日（金） 15:04」）、議事録の本文、「## 自分のメモ」、「## 文字起こし」（1 発話 1 行で「- [15:05] **話者**: 本文」）の順に並ぶ。選んでいないもの、中身のないものは含めない。
- **SHR-005** ［単体］ 議事録を含める指定で、議事録がまだない（または空の）ときは、代わりに自分のメモを入れる。
- **SHR-006** ［単体］ 文字起こしの話者は、自分の発話は設定の「自分の呼び名」（空なら「自分」）、相手の発話は「相手」と書く。
- **SHR-007** ［単体・E2E］ 「Markdown をコピー」を押すと、Markdown をクリップボードに入れ、「Markdown をコピーしました」と表示する。
- **SHR-008** ［単体・E2E］ 「ファイルに保存…」を押すと保存先を選ぶダイアログを出す。ファイル名の初期値は「2026-11-20 タイトル.md」（タイトルは 80 文字まで。Windows で使えない文字（`\ / : * ? " < > |`）と制御文字は「_」に置き換え、末尾のピリオドは除く。タイトルが空なら「無題のノート」）。保存すると「保存しました: <保存先>」と表示し、ダイアログを取り消したら何もしない。
- **SHR-009** ［単体・結合］〔実装待ち〕 保存先を選ぶダイアログで選べる種類は、「Markdown（.md）」と「テキスト（.txt）」。本体が保存を受け付けるのは、拡張子が .md・.markdown・.txt（大文字小文字は問わない）のファイルだけで、ほかの拡張子や拡張子なしの保存先は「保存できるのは .md / .markdown / .txt ファイルだけです」のエラーにし、ファイルを書かない。
  - **実装待ち**: 本体のエラーの文は、いまは「保存できるのは .md / .txt ファイルだけです」（.markdown が入っていない）。
- **SHR-010** ［単体・結合］ ファイルに書けなかったときは、「ファイルを保存できませんでした: 理由」を共有のメニューの中に表示する。
- **SHR-011** ［結合］ 保存するファイルの文字コードは UTF-8（BOM なし）で、内容は「Markdown をコピー」と同じになる。
- **SHR-012** ［単体・E2E］ コピー・保存の前に、まだ保存されていない入力（メモ・議事録の編集）を保存し、最新の内容を書き出す。
