# TRY: トレイと常駐

タスクトレイへの常駐、ウィンドウを閉じたときの動き、Windows の起動時の自動起動、終了。

- **TRY-001** ［E2E・手動］ メインウィンドウを × で閉じても、アプリは終了せず、ウィンドウが隠れるだけでタスクトレイに残る。会議の検出と録音は続く。
- **TRY-002** ［手動］ トレイのアイコンを左クリックすると、メインウィンドウを表示して手前に出す（最小化されていれば元に戻す）。
- **TRY-003** ［手動］ トレイのアイコンを右クリックすると、「Kiroscribe を開く」「会議を検出したら自動で録音」（チェック付き）「Kiroscribe を終了」のメニューを出す。アイコンに重ねると「Kiroscribe（会議の自動検出）」と表示する。
- **TRY-004** ［結合・手動］〔実装待ち〕 トレイのメニューの「会議を検出したら自動で録音」を選ぶと、設定の「会議の自動検出」のオン・オフが入れ替わって保存される。設定画面で変えて保存したときは、メニューのチェックもそれに合わせて変わる。設定画面を開いている間にトレイのメニューで切り替えたときは、設定画面の表示も切り替わり、そのあと「設定を保存」を押しても元に戻らない。
  - **実装待ち**: 設定画面の表示を追従させる部分。いまは、設定画面を開いたままトレイで切り替えても表示は変わらず、そのあと「設定を保存」を押すと元に戻る。
- **TRY-005** ［結合・手動］ 「Kiroscribe を終了」を選ぶと、録音中なら録音を止め、最後の発話の文字起こしが終わるのを待ってから終了する。
- **TRY-006** ［E2E・手動］ すでに起動しているときにもう一度起動すると、2 つ目は起動せず、起動中のメインウィンドウを表示して手前に出す。
- **TRY-007** ［E2E］ ふつうに起動したとき（スタートメニューなど）は、メインウィンドウを表示する。ウィンドウの大きさは幅 1240px・高さ 820px で始まり、幅 860px・高さ 560px より小さくはできない。
- **TRY-008** ［E2E・手動］ Windows の起動時に自動で起動したとき（`--autostart` 付き）は、ウィンドウを出さず、タスクトレイに常駐して会議を待つ。
- **TRY-009** ［手動］ 設定の「Windows の起動時に Kiroscribe を起動する」（最初はオン）をオンにして保存すると Windows の自動起動に登録し、オフにすると解除する。起動時にも、設定に合わせて登録をそろえる。登録するのはリリース用のビルドだけ（開発用のビルドは登録しない）。
- **TRY-010** ［E2E］ タスクトレイのアイコンを作れない環境でも、アプリは起動する。
