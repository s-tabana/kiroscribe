# NOTE: ノート

ノートの作成・一覧・検索・編集・自動保存・削除。

- **NOTE-001** ［単体・E2E］ 「新しいノート」を押すと、タイトルとメモが空のノートが作られて一覧の先頭に加わり、そのノートが開いてタイトル欄にフォーカスが当たる。検索欄に入力があれば空に戻す。
- **NOTE-002** ［単体・E2E］ Ctrl+N（または Cmd+N）を押すと、NOTE-001 と同じく新しいノートが作られる。
- **NOTE-003** ［単体］ ノートが 1 つもないときは、「最初の会議ノートを作りましょう」という案内と「新しいノート」ボタンを表示する。一覧には「まだノートがありません」と表示する。
- **NOTE-004** ［単体］ 一覧は作成日時の新しい順に並ぶ。ノートを編集しても、文字起こしが増えても、並びは変わらない。作成日時が同じなら、後に作ったノートが上になる。
- **NOTE-005** ［単体］ 一覧は日ごとの見出しでまとめる。見出しは、今日なら「今日」、前日なら「昨日」、それ以前の同じ年は「11月17日（火）」、別の年は「2025年12月31日（水）」の形になる。
- **NOTE-006** ［単体］ 一覧の各行には、タイトル（空なら「無題のノート」）、作成時刻（「9:05」の形。時はゼロ埋めしない）、プレビュー 1 行を表示する。録音中（仕上げ中を含む）のノートは、時刻の代わりに「録音中」の印を表示する。
- **NOTE-007** ［単体］〔見直し予定〕 プレビューは、議事録があれば議事録、なければ自分のメモから作る。見出し（# で始まる行）でない最初の空でない行を選び（見出ししかなければ最初の見出し）、行頭の記号（# - * ・ > と空白、チェックボックス「[ ] 」「[x] 」）を除く。60 文字を超えたら 60 文字で切って「…」を付ける。本体側（一覧の取得）と画面側（編集直後の反映）で同じ結果になる。ただし、チェックボックスの記号が 2 つ続く行（「- [ ] [ ] 〜」）だけは結果が違う（本体は続く記号をすべて除き、画面は 1 つだけ除く）。
- **NOTE-008** ［単体・結合・E2E］ 検索欄に文字を入れると、タイトル（空のノートは「無題のノート」として扱う）・プレビュー・自分のメモの本文・議事録・文字起こしのどれかにその文字を含むノートだけを一覧に表示する。大文字と小文字は区別しない。一致するノートがなければ「一致するノートがありません」と表示する。タイトルとプレビューは入力のたびにその場で絞り込み、メモの本文・議事録・文字起こしは本体に問い合わせて、結果が届いたら一覧に加える（問い合わせできないときは、タイトルとプレビューだけで絞り込む）。
- **NOTE-009** ［単体・E2E］ タイトルとメモへの入力は、入力が 0.5 秒止まると自動で保存する。保存の状態を「保存中…」「保存しました」「保存できませんでした」で表示し、失敗したときは理由も表示する。保存されると、一覧のタイトルとプレビューが更新される。
- **NOTE-010** ［単体・E2E］ 未保存の入力は、メモ欄からフォーカスが外れたとき、別のノートに切り替えたとき、議事録の作成や共有（書き出し）を始めるときに、0.5 秒を待たずに保存する。
- **NOTE-011** ［単体］ タイトル欄で Enter を押すと、メモ欄にフォーカスが移る（日本語入力の変換を確定する Enter では移らない）。
- **NOTE-012** ［単体］ ノートの上部に、作成日時を「2026年11月20日（金） 15:04」の形で表示する。
- **NOTE-013** ［単体］ ノートを開くと、議事録があれば議事録の表示で、なければ自分のメモの表示で開く。
- **NOTE-014** ［単体・E2E］ ノートの削除を選ぶと確認のダイアログ（「このノートを削除しますか？ メモ・文字起こし・議事録もすべて削除され、元に戻せません。」）を出す。OK ならノートを削除し、一覧で同じ位置にあった次のノート（末尾だった場合は 1 つ前）を開く。取り消したら何もしない。
- **NOTE-015** ［単体］ ノートを削除すると、そのノートの文字起こしと AI チャットの履歴も一緒に消える。会議の相棒の過去のノートの索引からも消える。
- **NOTE-016** ［単体・結合］ 録音中、または停止後の仕上げ中のノートは削除できない。「録音中のノートは削除できません。先に録音を停止してください」と知らせ、ノートは残る。
- **NOTE-017** ［単体］ 存在しないノートを開く・更新する・削除しようとすると、「ノートが見つかりません: <ノートの ID>」のエラーになる。
- **NOTE-018** ［単体］ ノートの更新は、渡した項目（タイトル・メモ・議事録）だけを変え、ほかの項目は保つ。更新日時は進む（前の値より戻らない）。
- **NOTE-019** ［結合・E2E］ ノート・文字起こし・議事録・チャットは、アプリを終了して起動し直しても残っている。
- **NOTE-020** ［単体・E2E］ 起動時にノートの一覧を読み込み、いちばん新しいノートを開く。読み込みに失敗したら、理由を画面上部の知らせに表示する。
