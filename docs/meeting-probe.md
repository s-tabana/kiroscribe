# 会議の手がかりの測り方

会議の自動検出の手がかりが、実際の PC で取れるかを `meeting_probe.exe` で測る手順です。
1 つの会議ごとに 2〜3 分、全体で 20 分ほどかかります。
測った結果は `probe-output.txt`（exe と同じフォルダ）に追記されるので、終わったらそのファイルを渡します。

## 準備

- `meeting_probe.exe` は、GitHub Actions の `meeting-probe` の実行の成果物から取ります。
- 起動は `meeting_probe.exe` だけで足ります。窓・部品・端点の実際の名前を見たいときだけ `--titles` を付けます。
- `--titles` の出力には、チャンネル名・参加者名・機器の名前が含まれえます。人に渡す前に中身を確かめます。
- 起動したら、窓を閉じずに最後まで置いておきます。終えるときは Ctrl+C を押します。

## 目印の打ち方

操作の区切りごとに、`meeting_probe.exe` の窓に短い 1 行を打って Enter を押します。
`◆ 目印 3: slack ミュートで入った` のように、時刻つきで記録されます。
以下の手順の「目印」の列は、打つ文の例です。

## 手順

### Slack のハドル

| 操作 | 目印 |
| --- | --- |
| ミュートのままハドルに入る | `slack ミュートで入った` |
| そのまま 2 分いる | `slack 2分たった` |
| ミュートを外して 20 秒ほど話す | `slack ミュート外した` |
| ハドルを退出し、Slack は開いたまま 1 分待つ | `slack 退出` |
| 環境設定の「オーディオとビデオ」で、マイクのテストを 1 回する | `slack マイクのテスト` |

### Discord の通話（デスクトップのアプリ）

| 操作 | 目印 |
| --- | --- |
| ミュートのままボイスチャンネルか通話に入る | `discord ミュートで入った` |
| そのまま 2 分いる | `discord 2分たった` |
| ミュートを外して 20 秒ほど話す | `discord ミュート外した` |
| 切断し、Discord は開いたまま 1 分待つ | `discord 退出` |

### Google Meet（ブラウザ）

ふだん使うブラウザ（Chrome・Edge・Zen など）で測ります。
会議でない別のタブ（ニュースなど）を、同じブラウザで開いたままにします。

| 操作 | 目印 |
| --- | --- |
| 会議の待機の画面を開く（まだ参加しない） | `meet 待機の画面` |
| 参加して 1 分いる | `meet 参加` |
| ミュートして 1 分いる | `meet ミュート` |
| 退出し、ブラウザは開いたまま 1 分待つ | `meet 退出` |

### Teams・Zoom

入れる会議があれば、Slack のハドルと同じ流れで測ります。
なければ省きます。

### 会議でないマイクの使用

ブラウザの音声入力（Google ドキュメントの音声入力など）か、録音のアプリを 1 つ、30 秒ほど使います。
始めと終わりに `音声入力 始め`・`音声入力 終わり` のような目印を打ちます。

## 対象のブラウザ

対象のブラウザは、次の実行ファイルの名前のものです。
同じ名前を使う版（Chrome と Edge の Beta・Dev・Canary、Firefox の Developer Edition・Nightly、Tor Browser の firefox.exe、Opera GX）も含みます。

| 系統 | 実行ファイルの名前 |
| --- | --- |
| Chromium 系 | chrome・msedge・brave・vivaldi・opera・opera_gx・arc・thorium・chromium・supermium・browser（Yandex）・whale・comet・dia・atlas・sidekick・island・duckduckgo |
| Firefox 系 | firefox・zen・floorp・librewolf・waterfox・mullvadbrowser |

一覧にないブラウザは、実行ファイルの版情報（製品名・会社名）から推定します。
録音・再生のセッションでは、子プロセスの起動の引数（Chromium の `--type=renderer` など、Firefox の `-contentproc`）からも推定します。
推定したものには「★一覧にないブラウザと推定（根拠: …）」と付きます。
製品が会議の判定に使うブラウザ（Chrome・Edge・Firefox・Brave・Vivaldi・Opera・Arc）より広く調べます。

## 出力の読み方

出力の前半は、製品と同じ判定（判定に使う手がかり・録音のセッションの一覧・判定・段階）です。
後半の「会議中を示しうる手がかり」は判定には使わず、変化した行だけが出ます。

| 行の先頭 | 中身 |
| --- | --- |
| `録音の端点`・`再生の端点` | 有効な端点の数と、既定・既定の通信の印。`--titles` のときは端点の名前 |
| `録音の既定のデバイス`・`再生の既定のデバイス` | 既定のデバイスと通信用の既定のデバイスが、どの端点か |
| `録音 端点N`・`再生 端点N` | アプリごとのセッションの状態（ブラウザには「（ブラウザ）」と付く）（active・inactive・expired）と音の大きさ（ピーク 0.000〜1.000 と、無音・小・中・大の区分）。区分か状態が変わったときに出る。消えたら「消失」。ブラウザの子プロセス（Chromium の音声サービスなど）なら、種類と親のブラウザも付く。プロセスを特定できなければ、理由とセッションの識別子（パスは実行ファイルの名前に縮めたもの）も付く |
| `録音 端点N の M 番目のセッション` | 状態やプロセス ID を読めなかったセッションと、その理由 |
| `窓` | 会議アプリとブラウザの窓（マイクを使っているかによらない）の、プロセス・クラス名・表示の様子・大きさ・名前の分類（名前なし・会議らしい名前・その他）。`--titles` のときは実際の名前 |
| `部品` | 窓の中の、退出・ミュート・カメラ・画面共有のボタンがあるかと、部品の種類。ミュートのボタンの名前が「解除」側なら「解除の名前」と付く。`--titles` のときは部品の名前 |
| `カメラ` | Windows の記録（ConsentStore の webcam）で、カメラを使用中のアプリと、最新の使用開始・終了の時刻 |
| `◆ 目印` | 打った目印 |

音声そのもの・本文・フルパスは記録しません。
音の大きさは数値だけです。
