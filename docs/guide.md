# Kiroscribe の使い方

会議中は要点だけメモし、終わったら AI が文字起こしと合わせて議事録に仕上げるアプリです。

## はじめに（最初の 1 回だけ）

1. 左上の歯車から **設定** を開きます。
2. **API キー** を 2 つ入力します。キーは、各欄の **キーを発行する** から発行できます。
   - **OpenAI**: 文字起こしに使います
   - **Anthropic**: 議事録と AI チャットに使います
3. Windows の「設定 → プライバシーとセキュリティ（Windows 10 では「プライバシー」） → マイク」で、**デスクトップ アプリがマイクにアクセスできるようにする** をオンにします。

> ヘッドホンをおすすめします。スピーカーだと相手の声がマイクにも入り、二重に記録されます。

## 会議を自動で記録する

Google Meet・Slack ハドル・Zoom・Teams・Discord で会議や通話に入ると、数秒後に右下へポップアップが出て、**自動で録音と文字起こしが始まります**。

- メモを取りたいときは、ポップアップの **ノートを開く** から書き込みます。
- 会議を抜けると、20 秒後に **自動で止まります**。
- **議事録を作成** を押すと、議事録ができあがります。
- 途中で止めたいときはポップアップの **停止** を押します。
- 続けて別のアプリの会議に入ったときは、会議ごとに別のノートに記録します。

自動録音は、設定の「会議の自動検出」か、タスクトレイのメニューでオフにできます。会議の途中でオンにすると、その会議から録音を始めます。

## 手動で記録する

1. **新しいノート**（Ctrl+N）を作ります。
2. **録音を開始** を押します。右側に文字起こしが出ます。
3. 終わったら **停止** を押します。

文字起こしのあるノートでは、ボタンが **録音を再開** になり、同じノートに続けて録音します。文字起こしには「2回目の録音（14:30〜）」のような区切りが入ります。議事録を作ったあとのノートで押すと、同じ会議の続きかを聞かれます。

- **続きとして録音**: 同じノートに続けて録音します。議事録は、録音の回ごとに節を分けて作ります。
- **新しいノートで録音**: 新しいノートを作って録音します。別の会議を録るときは、こちらを選ぶと議事録が混ざりません。

録音中は、タスクトレイのアイコンの右クリック → **録音を停止** でも止められます（ウィンドウを閉じているときも）。

## 長い録音の確認

録音が 1 時間を超えると、5 分ごとに、会議がまだ続いているかを確かめます。会議の検出が消えているとき、または自分と相手のどちらも 10 分間話していないときは、右下のポップアップで **会議は終わりましたか？** と聞きます。手動で始めた録音も対象です。

- **止める** を押すと、録音を止めて保存します。
- **続ける** を押すと、録音を続けます。次に聞くのは 30 分後です。
- 2 分たっても答えがないと、録音を止めて保存し、ポップアップと Windows の通知で知らせます。ただし、聞いたあとに話し声が戻っていれば（会議の検出が消えているときを除く）、止めずに録音を続けます。

## 議事録と AI チャット

- **議事録を作成**: メモと文字起こしから、概要・決定事項・ToDo などをまとめます。自分のメモ由来の行は濃く、AI が補った行は薄く表示されます。
- **AI チャット**: 「決まったことは？」「フォローアップのメール文案を作って」など、会議について質問できます。
- **共有**: 議事録・メモ・文字起こしを Markdown でコピー、またはファイルに保存できます。
- **検索**: 左上の検索欄で、タイトル・メモ・議事録・文字起こしに含まれる言葉から、ノートを探せます。

議事録や回答の作成は、**中止** でいつでも止められます。

## 困ったとき

| 症状 | 確かめること |
| --- | --- |
| 会議を検出しない | ブラウザの会議は、始まるときに会議のタブを表示していますか。設定の「会議の自動検出」はオンですか。それでも検出しないときは、下の「デバッグ用のログ」を保存して、開発者に送ってください |
| 「マイクを使う許可がありません」と出る | Windows の **設定 → プライバシーとセキュリティ（Windows 10 では「プライバシー」） → マイク** で、「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」をオンにしてください |
| 文字起こしが出ない | 設定の OpenAI の API キー、インターネット接続 |
| 「API キーを確認してください」と出て録音が止まった | OpenAI の API キーが正しくありません。設定で入れ直してから、もう一度録音を始めてください |
| 議事録が作れない | 設定の Anthropic の API キー |
| 相手の声が「自分」にも入る | ヘッドホンを使ってください |
| ウィンドウを閉じたのに動いている | タスクトレイに残っています。終了はトレイアイコンの右クリック → **Kiroscribe を終了** |
| 「Kiroscribe を起動できませんでした」と出る | 表示された理由（データのファイルを開けない、など）を確かめてください。データは変更されていません |

### デバッグ用のログ

Kiroscribe は、不具合の原因を調べるために、アプリの動き（起動と終了、更新の確認、会議の検出の判断、録音、文字起こしと AI の処理の成否と時間、エラー）を PC の中に記録しています。記録は 7 日分（合計 20MB まで）で、古いものから消えます。

- 設定の「このアプリについて」の **デバッグ用のログを保存…** で、記録と、会議の検出の記録（マイクを使ったアプリの名前と、マイクを使っているブラウザのタブの名前）、アプリと OS のバージョン、設定（API キーは設定済みかどうかだけ）を 1 つの zip に保存できます。開発者に送るときに使ってください
- 録音・ノート・文字起こし・議事録・AI チャットの内容と API キーは、記録にも zip にも入りません。タブの名前には会議でないページやメールの件名も入ることがあるので、送る前に zip を開いて、見せたくない内容がないか確かめてください
- 不具合がまた起きそうなときは、**詳しい記録を残す（24 時間）** をオンにしてから再現させると、原因を調べやすくなります（会議の検出で見たブラウザのタブの名前なども記録します）。24 時間たつと、自動でオフに戻ります

## 更新

新しいバージョンが出ると、左下と設定画面に知らせが出ます。左下の **更新**、または設定画面の **更新して再起動** を押すと、ダウンロードが終わりしだい、新しいバージョンで起動し直します。録音中と、AI が議事録や回答を作っている間は更新できません。

設定の「このアプリについて」で **新しいバージョンを自動でインストールする** をオンにすると、自動で更新します（最初はオフです）。

- 新しいバージョンを自動でダウンロードし、ウィンドウを閉じている間にインストールします。録音中と、AI が議事録や回答を作っている間は更新しません。
- ウィンドウを開いている間は、勝手に再起動しません。「準備ができました」と知らせが出るので、ウィンドウを閉じるか、**今すぐ更新** を押します。
- 更新したあとは、次にウィンドウを開いたときに左下で知らせます。
