# CHT: AI チャット

ノートの内容について AI に質問する。

- **CHT-001** ［単体］ AI チャットのパネルを開くと、そのノートのこれまでの質問と回答を古い順に表示する。まだ何もないときは、説明と質問の例 4 つ（「この会議で決まったことは？」「自分の ToDo をまとめて」「相手の懸念点は？」「フォローアップのメール文案を作って」）を表示する。
- **CHT-002** ［単体］ 質問の例を押すか、入力欄に書いて Enter（または「送信」）で質問を送る。Shift+Enter は改行になる。日本語入力の変換を確定する Enter では送らない。空白だけのときは送れない。
- **CHT-003** ［単体・E2E］ 送ると入力欄が空になり、質問と「考えています…」を表示する。回答は届いた分から順に表示し、終わると質問と回答が履歴に残る。
- **CHT-004** ［単体・結合］ Anthropic の API キーが未設定だと送れず、理由を知らせて（「設定を開く」ボタン付き）、質問を入力欄に戻す。このとき質問は履歴に残らない。
- **CHT-005** ［結合］ 質問は、AI に送る前に履歴へ保存する。AI の応答が失敗・中止したときは、その質問を履歴から消し、質問を入力欄に戻す。送り直しても、同じ質問が履歴に 2 つ並ばない。
- **CHT-006** ［単体・結合・E2E］ 回答の作成中に「中止」を押すと止まり、エラーの知らせは出さない。回答は保存されない（質問も履歴に残さず、入力欄に戻す。CHT-005）。中止は、MIN-005 と同じく、押してすぐに効く。
- **CHT-007** ［単体］ AI には、これまでの会話のうち新しいほうから 20 件までを送る。同じ側の発言が続いているところは 1 つにまとめ、利用者の発言から始まるようにする。
- **CHT-008** ［単体・結合］ AI には、ノートのタイトル・日時・自分のメモ・議事録（あれば）・文字起こしを、質問に答える根拠として渡す。effort は low、出力の上限は 16,000 トークン、モデルは設定の Claude のモデルを使う。
- **CHT-009** ［結合］ 空の質問を送ると「質問を入力してください」のエラーになる。AI の回答が空だったときは「回答が空でした。もう一度お試しください」のエラーになり、回答は保存しない。
- **CHT-010** ［単体］ 同じノートで回答を作成している間にもう一度送ると、「回答を作成中です」のエラーになる（画面では、作成中は送信できない）。
- **CHT-011** ［単体］ 履歴の消去を選ぶと確認のダイアログを出し、OK ならそのノートの履歴だけを消して、質問の例の表示に戻る。ほかのノートの履歴は消えない。
- **CHT-012** ［単体］ 回答は Markdown として整えて表示する。質問は書いたままの文字で表示する。
- **CHT-013** ［結合・手動］ 実際の Anthropic の API で、会議の内容についての質問に回答が返る。設定画面で選べるすべてのモデルで、アプリと同じ送り方（ストリーミング）が受け付けられる（API キーを登録した CI で、週に 1 回確かめる）。
- **CHT-014** ［単体・E2E］ 回答の作成中に AI チャットのパネルを閉じても（別のノートへ移っても）、作成は裏で続く。作成中にパネルを開き直すと、質問と、それまでに届いた回答（まだなら「考えています…」）と「中止」を表示し、終わると回答に切り替わる（質問は 1 つだけ表示する）。パネルを閉じているあいだに失敗したときも理由を知らせ、次にパネルを開いたときに、その質問を入力欄に戻す。
