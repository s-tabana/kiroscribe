# POP: ポップアップ

会議を検出したときに画面の右下に出す小さなウィンドウ。

- **POP-001** ［E2E・手動］ ポップアップは、主モニターの右下（右端から 16px、下端から 64px 内側）に、幅 380px・高さ 128px、枠なし、常に手前、タスクバーには出さない形で表示する。表示するときに、ほかのウィンドウからフォーカスを奪わない。
- **POP-002** ［単体・E2E］ ポップアップがすでに出ているときに次の知らせが来たら、新しいウィンドウは出さず、表示の内容だけを入れ替える。ポップアップを開いた時点の最新の内容を表示する。
- **POP-003** ［単体］ 録音を始めたときは、会議の名前、「自動で録音・文字起こしを始めました」、経過時間（そのノートを録音している間）、「ノートを開く」「停止」を表示する。
- **POP-004** ［単体・E2E］ ポップアップの「停止」を押すと録音を止め、仕上げの間は「録音を停止しました。文字起こしを仕上げています…」、終わると停止の表示（POP-005）に変わる。会議が終わって自動で止まるときの仕上げの間は、「会議が終わりました。文字起こしを仕上げています…」と表示する。
- **POP-005** ［単体］ 録音を止めたあとは、「録音を停止しました。「<ノートのタイトル>」に保存しています。」と「ノートを開く」「議事録を作成」を表示する。この表示は 30 秒たつと自動で閉じる。
- **POP-006** ［単体］ 自動で録音できなかったときは、理由と「設定を開く」を表示する。
- **POP-007** ［単体・E2E］ 「ノートを開く」を押すと、メインウィンドウを表示して手前に出し、そのノートを開き（検索欄は空に戻す）、ポップアップを閉じる。
- **POP-008** ［単体・E2E］ 「議事録を作成」を押すと、POP-007 と同じようにノートを開き、議事録の作成を始める（MIN-018）。
- **POP-009** ［単体・E2E］ 「設定を開く」を押すと、メインウィンドウを表示して設定画面を開き、ポップアップを閉じる。
- **POP-010** ［単体］ ポップアップの ×（閉じる）は、ポップアップを閉じるだけで、録音は続く。
- **POP-011** ［単体・結合］ 録音中の表示とエラーの表示は、利用者が閉じるか、次の知らせで入れ替わるまで出たままになる（自動では閉じない）。自動で始めた録音をメインウィンドウの「停止」で止めたときは、ポップアップも停止の表示（POP-005）に変わる（ポップアップを閉じていたときは、出し直さない）。ポップアップの「停止」が止めるのは、そのポップアップが知らせている録音だけで、その録音がもう終わっていたら、停止の表示に変えるだけにする。
- **POP-012** ［手動］ ポップアップは、上部をドラッグして移動できる。
- **POP-013** ［単体］ ポップアップには、アプリの更新の知らせを出さない。
