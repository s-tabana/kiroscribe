# IPC: 画面と本体の取り決め

画面（React）と本体（Rust）の間で交わす、コマンドとイベントの名前と形。利用者からは見えないが、片方だけを変えると動かなくなるため、項目にして守る。

- **IPC-001** ［単体・結合］ 画面が呼ぶコマンドは、すべて本体に登録されている（43 個: list_notes・search_notes・create_note・get_note・update_note・delete_note・get_settings・save_settings・get_api_key_status・set_api_key・export_markdown・save_markdown・list_audio_devices・list_segments・list_transcript_breaks・get_recording_status・start_recording・pause_recording・resume_recording・stop_recording・answer_recording_check・enhance_note・cancel_ai・list_chat_messages・clear_chat_messages・send_chat_message・get_popup_state・close_popup・open_note_from_popup・open_settings_from_popup・get_debug_log_status・set_debug_verbose・write_debug_log・save_debug_bundle・submit_debug_logs・get_guide・get_release_notes・open_external・get_app_version・get_update_status・check_for_update・install_update・take_update_notice）。画面が呼ばないコマンドは登録しない。
- **IPC-002** ［単体・結合］ コマンドの引数の名前は、画面と本体で一致する（画面は noteId・patch・settings・provider・value・options・path・content・kind・enhance・deadline・keep・url・id・query・enabled・level・event・fields・requestId の名前で渡す）。
- **IPC-003** ［単体・結合］ コマンドの戻り値とイベントの中身は、項目の名前（camelCase）と値の型が、画面の型の定義と一致する。コマンドの戻り値は次のとおり: ノートの要約の一覧（list_notes）、ノートの ID の一覧（search_notes）、ノート（create_note・get_note・update_note・enhance_note）、設定（get_settings・save_settings）、API キーの状態（get_api_key_status・set_api_key）、書き出しの結果（export_markdown）、マイクの一覧（list_audio_devices）、文字起こしの一覧（list_segments）、文字起こしの区切りの一覧（list_transcript_breaks）、録音の状態（get_recording_status・start_recording・pause_recording・resume_recording・stop_recording）、チャットの一覧（list_chat_messages）、チャット 1 件（send_chat_message）、ポップアップの内容か null（get_popup_state）、デバッグ用のログの状態（get_debug_log_status・set_debug_verbose。「詳しい記録」の期限の UNIX ミリ秒か null）、zip に入れたファイルの数（save_debug_bundle）、ログの提出の結果（submit_debug_logs。提出の番号 id と受け取った時刻 receivedAt）、使い方（get_guide）、リリースノート（get_release_notes）、バージョンの文字列（get_app_version）、更新の状態（get_update_status・check_for_update）、更新後のバージョンの文字列か null（take_update_notice）、値なし（null。delete_note・save_markdown・answer_recording_check・cancel_ai・clear_chat_messages・close_popup・open_note_from_popup・open_settings_from_popup・write_debug_log・open_external・install_update）。
- **IPC-004** ［単体・結合］ 決まった値の書き方は、画面と本体で一致する: キーの種類は openai・anthropic、話者は me・them、チャットの役は user・assistant、録音の状態は idle・recording・paused・finishing、更新の段階は idle・downloading・installing、ヘルプの出どころは network・cache・bundled、ポップアップの種類は recording・finishing・stopped・error・confirmEnd・stoppedUnanswered、AI の種類は enhance・chat。
- **IPC-005** ［結合・E2E］ 本体が画面に送るイベントの名前と中身は、画面が待ち受けるものと一致する: recording-status（録音の状態）、transcript-segment（文字起こし 1 件）、transcript-break（文字起こしの区切り 1 件）、audio-level（話者と大きさ）、recording-error（ノートの ID と文）、enhance-delta・chat-delta（ノートの ID と届いた文字）、note-created（ノート）、open-note（ノートの ID と、議事録を作るかどうか。メインウィンドウ宛て）、open-settings（メインウィンドウ宛て）、main-shown（中身なし。メインウィンドウ宛て）、settings-changed（設定。設定画面の外で設定が変わったときの、保存後の設定）、meeting-popup（ポップアップの内容。ポップアップ宛て）、update-status（更新の状態）、log-submit-progress（提出コマンドに渡した識別子 `requestId`、送った大きさ、全体の大きさ）。
- **IPC-006** ［結合］ コマンドが失敗したとき、画面は理由を 1 つの文字列として受け取る。
- **IPC-007** ［単体・E2E］ メインウィンドウの名前は main、ポップアップの名前は meeting-popup。ポップアップは、メインウィンドウと同じ画面のコードを `index.html#/popup` で開く。
- **IPC-008** ［単体・結合］ 自動インストールのための取り決め: 設定に autoUpdate（真偽値）がある。更新の状態（update-status）に ready（真偽値。ダウンロードと署名の確認が済んでいる）がある。コマンド take_update_notice は、自動で更新したあとの知らせ（更新後のバージョンの文字列）を 1 回だけ返し、メインウィンドウを表示していないとき・知らせるものがないときは null を返す。イベント main-shown は、閉じていたメインウィンドウを表示したときに送る。
