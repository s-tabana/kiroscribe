# SEC: セキュリティ上の約束

利用者に約束していること。壊れると被害が大きいので、すべて自動テストで守る。

- **SEC-001** ［単体・結合］ 保存した API キーの値は、画面（WebView）に返さない。画面が受け取るのは、キーごとの「設定済みかどうか」と、保存先の説明だけ。
- **SEC-002** ［結合・E2E］ API キーは、データベース・設定・書き出したファイル・ログに書かない（Windows では資格情報マネージャーにだけ保存する）。
- **SEC-003** ［単体］ API キーの入力欄は、入力した文字を伏せて表示する。保存したあとは入力欄を空にし、保存済みのキーを欄に表示しない。
- **SEC-004** ［単体・結合］ OpenAI のキーは OpenAI の API（`https://api.openai.com/v1`）にだけ、Anthropic のキーは Anthropic の API（`https://api.anthropic.com/v1`）にだけ送る。GitHub への問い合わせには、どちらのキーも付けない。
- **SEC-005** ［単体］ 外部との通信は、OpenAI（文字起こし）・Anthropic（議事録と AI チャット）・GitHub（更新とヘルプ）と、デバッグ用のログの回収の入口（`https://log-intake.seita-tabana.workers.dev`。SEC-015 の条件のときだけ）だけで、すべて `https://` で行う。
- **SEC-006** ［単体・E2E］ 画面（WebView）からは、外部に接続できない（Content Security Policy で、アプリ自身と本体との通信だけを許可する）。外部の画像・スクリプト・スタイルは読み込めない。
- **SEC-007** ［単体］ 画面（WebView）に許可する操作は、ウィンドウの基本操作とドラッグ、保存先を選ぶダイアログ、確認とメッセージのダイアログ、クリップボードへの書き込みだけ。ファイルの読み書き、プログラムの実行、更新の実行、外部の URL を開く権限は、画面に渡さない（本体のコマンドを通す）。
- **SEC-008** ［単体・結合］ 既定のブラウザで開く URL は、`https://` で始まるものだけ。2048 文字を超えるもの、制御文字を含むもの、ホストがないもの、ユーザー名やパスワードを含むもの（見た目と行き先が違う URL）、`http:`・`file:`・`javascript:`・`mailto:` などは開かず、「このリンクは開けません（https:// で始まるリンクだけを開けます）」のエラーにする。
- **SEC-009** ［単体］ 議事録・AI チャット・ヘルプ・更新の変更点として表示する文章は、HTML として解釈しない（埋め込まれたタグやスクリプトは動かない）。画像は表示しない。議事録・AI チャット・更新の変更点の中のリンクは押せない。
- **SEC-010** ［結合・E2E］ 更新のファイルは、アプリに埋め込んだ公開鍵で署名を確かめてからインストールする。署名のないファイル、署名の合わないファイル、別のバージョンとして署名されたファイルはインストールしない。
- **SEC-011** ［E2E］ 音声は、文字起こしのために OpenAI へ送るだけで、ファイルとして保存しない。ノート・文字起こし・議事録・チャットは、この PC の中にだけ保存する。
- **SEC-012** ［E2E］ 配布するビルド（cargo の feature `e2e` なし）には、テスト用の差し替え（作業フォルダを指す環境変数 `KIROSCRIBE_E2E_DIR`・起動の引数 `--kiroscribe-e2e-dir` と、接続先・ログの回収の入口・更新の取得元と公開鍵・会議の検出・音声・ダイアログなどの差し替え）のコードが入らない。この環境変数や引数を付けて起動しても、何も変わらない。配布する実行ファイルにこのコードがないことを、CI とリリースのたびに検査する。
- **SEC-013** ［単体・結合］ 会議の検出は PC 内で行う。検出に使うのは、会議の判定表（MTG-001）の対象のアプリの名前、その窓の題とクラス名、その窓の中の部品（ボタン・タブ）の名前と種類、部品を調べるブラウザの窓でブラウザが表示を確定したページのホスト名（ブラウザ自身のアドレスバーと、ページの本文の URL から読む。URL のパスとクエリは読んだその場で捨てる。MTG-031）、オーディオのセッションの状態と再生の音の大きさの数値（ピーク）だけ。検出のために、画面の画像や音声そのものは調べない。ほかのアプリの窓の中は調べない（MTG-029）。
  検出の記録（MTG-025）に残るアプリ名とウィンドウ／タブ名を外部に送るのは、本人がログの提出に明示的に同意した場合（SEC-015）に限る。
- **SEC-014** ［単体・結合］ OpenAI・Anthropic が返したエラーの文に API キーの断片（`sk-` で始まる文字列。`sk-...abcd` のように伏せ字を含むものも）が含まれていたら、その部分を「（キーは表示しません）」に置き換える。エラーの知らせとログに、API キーの値やその一部を出さない。
- **SEC-015** ［単体・結合］ デバッグ用のログは、利用者が「デバッグ用のログを提出…」を押し、送るもの・送らないものを示した確認で OK を選んだときだけ送る。
  送り先は固定の `https://log-intake.seita-tabana.workers.dev/v1/logs/kiroscribe` とする。
  送信前に、入口の URL が HTTPS、許可したホスト、既定のポートを使うことを確かめる。
  入口の URL にユーザー名・パスワード・パス・クエリ・フラグメントを含めず、リダイレクトにも従わない。
  送り先と提出用の値（`X-Log-Token`）は設定に持たず、画面（WebView）からは変えられない。
  送る本文は「デバッグ用のログを保存…」と同じ zip とする。アプリの版、導入ごとの乱数 ID、提出用の値をヘッダーに付ける。乱数 ID に利用者名や端末名を含めない。
  zip に含まれる会議検出の記録にはアプリ名とウィンドウ／タブ名がある。
  録音・ノート・文字起こし・議事録・AI チャットの内容と API キーは送らない。
  送ったログは開発者だけが見られる場所に保管し、30 日で削除する。
  E2E テスト用のビルドでは、作業フォルダで指定した手元の模擬サーバー（`127.0.0.1`・`localhost`・`[::1]`）にだけ送る。作業フォルダや送り先の指定が使えなければ送らない。
