# REC: 録音

録音の開始・一時停止・再開・停止と、録音中の表示。音声を文字にする部分は「文字起こし」の節。

- **REC-001** ［単体・結合・E2E］ 「録音を開始」を押すと、マイク（「自分」）と、設定がオンなら PC から流れる音声（「相手」）の取り込みを始める。状態が「録音中」になり、経過時間が進む。
- **REC-002** ［単体・結合］ OpenAI の API キーが未設定だと録音は始まらず、「API キーが設定されていません（OpenAI）。設定画面から入力してください」と知らせる。知らせには「設定を開く」ボタンが付く。
- **REC-003** ［結合］ 同時に録音できるノートは 1 つだけ。別のノートで録音中に開始しようとすると「別のノートで録音中です。先にそちらの録音を停止してください」のエラーになる。同じノートでもう一度開始しても、エラーにせず今の状態を返す（録音は二重に始まらない）。
- **REC-004** ［結合］ 前の録音の仕上げ中（停止後、残りの文字起こしを待っている間）に開始しようとすると、「前の録音の文字起こしを仕上げています。少し待ってから開始してください」のエラーになる。
- **REC-005** ［結合］ 存在しないノートでは録音を開始できない（「ノートが見つかりません: <ノートの ID>」）。
- **REC-006** ［単体・結合］ 「一時停止」を押すと、経過時間が止まる。一時停止した時点までの発話は文字起こしされ、一時停止中の音声は捨てて、どこにも送らない。
- **REC-007** ［単体・結合］ 「再開」を押すと、経過時間は一時停止していた時間を除いて続きから進む。再開後の発話には、再開後の実際の時刻が付く。
- **REC-008** ［結合］ 録音していないとき（仕上げ中を含む）に一時停止・再開を呼ぶと、「録音していません」のエラーになる。一時停止中にもう一度一時停止しても、録音中に再開を呼んでも、エラーにはならず状態は変わらない。
- **REC-009** ［単体・結合・E2E］ 「停止」を押すと、音声の取り込みを止め、話している途中だった発話も文字起こしに回す。残りの文字起こしがすべて終わるまで「文字起こしを仕上げています…」と表示し、終わると録音していない状態に戻る。
- **REC-010** ［結合］ 録音していないときに停止を呼んでも、エラーにせず今の状態を返す。
- **REC-011** ［単体］ 経過時間は「3:07」の形、1 時間以上は「1:02:07」の形で表示し、一時停止していた時間は含めない。
- **REC-012** ［単体］ 録音中は、取り込んでいる音源（自分・相手）ごとに入力の大きさを 5 段階のバーで表示し、約 0.1 秒ごとに更新する。ごく小さい音（0.003 以下）は 0 本、-50dB〜-10dB を 1〜5 本にする。一時停止・停止するとバーは 0 に戻る。
- **REC-013** ［単体］ 録音中に別のノートを開くと、そのノートには録音開始のボタンを出さず、「別のノートで録音中 <経過時間>」と「そのノートを開く」を表示する。押すと録音中のノートに移る。
- **REC-014** ［単体］ あるノートで録音が始まると、そのノートの文字起こしのパネルが自動で開き、「ライブ」の印が付く。
- **REC-015** ［単体・E2E］ 文字起こしが 1 件以上あるノートでは、開始のボタンが「録音を再開」になる。押すと同じノートで録音が始まり、新しい発話は既存の文字起こしの後に加わる。
- **REC-016** ［単体・E2E］ 録音の状態（録音中・一時停止中・仕上げ中・なし）が変わると、開いているすべてのウィンドウ（メイン・ポップアップ）の表示が変わる。ウィンドウを開き直したときも、そのときの状態を表示する。
- **REC-017** ［結合・E2E］ 設定の「相手の声（PC から流れる音声）も取り込む」がオフなら、マイクだけを取り込む。
- **REC-018** ［単体・E2E］ 相手の声の取り込みを始められなかったとき（出力デバイスがない、Windows 以外、など）は、マイクだけで録音を続け、「相手の声は取り込まず、マイクだけで録音します（理由）」と知らせる。文字起こしのパネルの下に「相手の声は取り込んでいません（マイクのみ）」と表示する。
- **REC-019** ［E2E］ 設定で選んだマイクが見つからないときは、既定のマイクで録音し、「選択したマイクが見つからないため、既定のマイクで録音します」と知らせる。
- **REC-020** ［E2E］ 使えるマイクがないときは録音が始まらず、「マイクが見つかりません。接続と Windows のプライバシー設定（マイクへのアクセス）を確認してください」と知らせる。
- **REC-021** ［単体・E2E］ 録音中に音声デバイスで問題が起きたとき（一時的な取りこぼしを除く）は、「自分（または相手）の音声デバイスでエラーが発生しました: 理由」と知らせ、録音は続ける。
- **REC-022** ［単体・E2E］ Windows のプライバシー設定でマイクを使うことが許可されていないときは、録音を始めず、「マイクを使う許可がありません。Windows の「設定」→「プライバシーとセキュリティ」（Windows 10 では「プライバシー」）→「マイク」で、「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」をオンにしてください」と知らせる（Windows の英語の技術的な文は出さない）。
- **REC-023** ［単体・結合］ 録音（手動で始めたものと、会議の自動検出で始めたものの両方）が、一時停止していた時間を除いて 1 時間を超えたら、それ以降は 5 分ごとに、会議が続いているかを確かめる。一時停止している間は確かめない。
- **REC-024** ［単体・結合］ 確かめたときに次のどちらかに当てはまれば、会議が終わったとみなして、ポップアップで確認を出す（POP-014）。どちらにも当てはまらなければ、5 分後にまた確かめる。(1) この録音の間に会議を検出していて（MTG-007 の開始）、いまは検出していない（MTG-008 の終了のあと）。(2) 自分と相手のどちらにも、10 分間、発話（TRN-001〜TRN-003 で発話として区切ったもの）がない。録音を始めた時点と、一時停止から再開した時点は、発話があったものとして数える。会議を一度も検出していない録音（対面の会議など）は、(2) だけで判断する。
- **REC-025** ［単体・結合］ 確認で「止める」を選ぶと、その録音を止めて保存し、ポップアップを停止の表示（POP-005）にする。「続ける」を選ぶと、録音を続け、30 分たってから、また 5 分ごとに確かめる（確認を出していないときに届いた「続ける」では、次に確かめる時刻を延ばさない）。
- **REC-026** ［単体・結合・手動］ 確認を出してから 2 分たっても答えがなければ、REC-024 の条件をもう一度確かめる。当てはまれば、録音を止めて保存し、ポップアップ（POP-015）と Windows の通知で「答えがなかったため、録音を停止しました。「<ノートのタイトル>」に保存しています。」と知らせる（一時停止中でも止める）。当てはまらなくなっていれば（確認のあとに発話があった、など）、確認を取り下げ、5 分後にまた確かめる。
