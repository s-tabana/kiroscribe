# LOG: デバッグ用のログ

不具合（会議を検出しなかった、録音が止まった など）の原因を後から調べるために、アプリの動きを PC の中に記録し、1 つにまとめて書き出す。

- **LOG-001** ［単体］ ログは、アプリのデータの場所の `logs` フォルダに、日ごとのファイル `kiroscribe-<年月日>.log` として書く。1 行に 1 つの出来事を JSON で書き、時刻・重さ（info・detail・error）・起きた場所（本体は app、画面は ui）・出来事の名前・値を入れる。
- **LOG-002** ［単体］ 起動して最初に書くときと、日付が変わって最初に書くときに、今日を含めて 7 日より前のファイルを消す。残りの合計が 20MB を超えるときは、今日のファイルを除いて古いものから消す。1 日のファイルは 10MB までとし、達したらその日はそれ以上書かず、達したことを 1 行だけ書く。
- **LOG-003** ［結合・E2E］ アプリの起動（アプリのバージョン、OS の名前とバージョン、Windows のビルド番号、CPU の種類、Windows の起動時の起動か）と終了を書く。起動時にデータを開けなかったときは、その理由を書く。
- **LOG-004** ［結合］ 更新の確認の結果（いまのバージョンと、見つけた新しいバージョン）を書く。確認・ダウンロード・インストールに失敗したときは、その理由を書く。
- **LOG-005** ［単体・結合］ 会議の検出では、判定の様子を、様子が変わったときと、変わらなくても 60 秒ごと（「詳しい記録」のときは 15 秒ごと）に書く。書くのは、マイクを使っているアプリの名前（Kiroscribe 自身を除く。実行ファイルの名前かストアアプリのパッケージ名）、見たブラウザのウィンドウの数、判定とその理由（マイクを使っているアプリがない／会議アプリでもブラウザでもない／ブラウザに会議のタブが見えない／会議アプリがマイクを使っている／会議のタブが見えている）、開始・終了の確定の段階（会議なし・開始の確定待ち・会議中・終了の猶予の間）と、確定待ちなら待ち始めてからのミリ秒。Windows では、マイクの使用状況の記録を開けたかと、記録の件数、会議アプリかブラウザに見える記録ごとの名前・名前の分類（実行ファイル・パッケージ名・ほか）・置き場所の区分（Program Files・AppData・WindowsApps など）・会議アプリとして当たるか・使用中か・使用の開始と終了の時刻の値（Start・Stop）とそれからの経過秒も書く。会議の開始・終了を確定したときと、開始を受けて自動で録音を始めたこと、始めなかった理由（会議の自動検出がオフ・ほかの録音中・OpenAI の API キーが未設定・ノートを作れない・録音を始められない）、終了を受けて録音を止めなかった理由も書く。利用者の名前を含むフルパスは書かない。
- **LOG-006** ［結合］ 録音の開始（ノート、自動で始めたならその会議アプリ、マイクを選んであるか、相手の声を取り込むか、文字起こしのモデルと言語）、一時停止、再開、停止（録音の時間、残りの文字起こしの仕上げにかかった時間）を書く。始められなかったときと、録音中のエラーは、その理由を書く。長い録音で会議が終わったかを確かめた結果と、確認への答えも書く。
- **LOG-007** ［結合］ 文字起こしは、録音を止めたときに、成功と失敗の回数、かかった時間の合計と最長を書き、失敗したときはその都度、理由と時間を書く。AI の処理（議事録の作成と AI チャット）は、始まり（種類・ノート・モデル）と、終わり（成功・中止・失敗の理由）とかかった時間を書く。
- **LOG-008** ［単体・結合］ 画面の出来事も、本体のログに書く: 画面を開いたこと、捕まえられなかったエラー（エラーの文と、起きたファイルの名前と行）、本体のコマンドが失敗したこと（コマンドの名前と理由。引数は書かない）。画面から書いた出来事の名前は「ui.」で始める。
- **LOG-009** ［単体・結合］ ログには、API キー、録音した音声、文字起こし・メモ・議事録・AI チャットの本文、AI に送った内容と返ってきた内容を書かない。念のため、文字列の値は 300 文字で切り、API キーの形の文字列（`sk-` で始まるもの）と、パスの中の利用者のフォルダの名前を伏せてから書く。
- **LOG-010** ［単体・結合］ 設定画面の「このアプリについて」の「詳しい記録を残す（24 時間）」をオンにすると、その時から 24 時間だけ、細かい出来事（会議の検出で見た、マイクを使っているブラウザのウィンドウのタイトル、文字起こしの 1 回ごとの成否と時間）も書く。オンの間は「<月>/<日> <時>:<分> まで、細かい出来事も記録します。時間が過ぎると、自動でオフに戻ります。」と表示する。期限はアプリを起動し直しても残り、過ぎたら自動でオフに戻して、戻したことを書く。
- **LOG-011** ［単体・結合・E2E］ 設定画面の「このアプリについて」の「デバッグ用のログを保存…」を押すと、保存ダイアログ（既定の名前は「kiroscribe-debug-<年月日>-<時分>.zip」）を出し、ログのファイル、会議の検出の記録（MTG-026）、環境の情報（アプリと OS のバージョン、Windows のビルド番号、CPU の種類、詳しい記録の期限、秘密でない設定）、中身の説明を 1 つの zip にまとめて保存し、「デバッグ用のログを保存しました: <保存した場所>」と表示する。設定のうち API キーは設定済みかどうか、自分の呼び名とマイクは決めてあるかどうかだけを入れる。保存できるのは .zip ファイルだけ。取り消したら何も表示しない。保存できなかったら理由を表示する。ボタンの下に、zip に入るものと入らないもの（録音・ノート・文字起こし・議事録・AI チャットの内容と API キー）を書く。あわせて、タブの名前には会議でないページやメールの件名も入ることがあるので、人に渡す前に zip を開いて見せたくない内容がないか確かめるよう書く。
