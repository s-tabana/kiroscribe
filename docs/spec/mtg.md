# MTG: 会議の自動検出

会議が始まったことを検出して自動で録音し、終わったら止める（Windows）。

- **MTG-001** ［単体］ 次のデスクトップアプリがマイクを使っている間は、会議中とみなす: Slack（slack.exe）、Zoom（zoom.exe・cpthost.exe）、Teams（ms-teams.exe・teams.exe、またはパッケージ名が MSTeams_・MicrosoftTeams_ で始まるもの）、Discord（discord.exe・discordptb.exe・discordcanary.exe）。大文字小文字は区別しない。
- **MTG-002** ［単体］ ブラウザ（chrome・msedge・firefox・brave・vivaldi・opera・arc）がマイクを使っていて、そのブラウザ自身の表示中のウィンドウのタイトルが会議のものなら、会議中とみなす（マイクを使っているのとは別のブラウザのウィンドウのタイトルでは、会議とみなさない）。Google Meet は「google meet」「meet.google.com」「 - meet - 」を含むか、「meet - 」「meet – 」「meet: 」「meet：」で始まるもの。Slack は「slack」と「huddle」か「ハドル」を含むもの。Teams は「microsoft teams」と「meeting」「会議」「call」「通話」のどれかを含むもの。Zoom は「zoom」と「meeting」か「ミーティング」を含むもの。Discord は、Discord の画面のタブ名の形のもの（「Discord | 」で始まる、または「 | Discord」「 - Discord」で終わる。前に未読の印「(3)」「•」が付いていても、後ろにブラウザの名前が付いていてもよい）。タイトルに「discord」を含むだけのページ（Discord についての記事や検索結果など）は、会議とみなさない。
- **MTG-003** ［単体］ 会議アプリ以外がマイクを使っていても、ブラウザが会議以外のサイトでマイクを使っていても、会議とはみなさない。
- **MTG-004** ［単体］ 会議のページを開いているだけ（ブラウザがマイクを使っていない）では、会議とはみなさない。以前マイクを使っていて、いまは使っていないアプリも対象にしない。
- **MTG-005** ［単体］ Kiroscribe 自身がマイクを使っていること（録音中）は、判定に入れない。
- **MTG-006** ［単体］ デスクトップの会議アプリとブラウザの会議の両方が当てはまるときは、デスクトップの会議アプリとして扱う。
- **MTG-007** ［単体］ 2 秒ごとに調べ、同じ会議が 4 秒続けて検出されたら「会議の開始」とする。途中で検出が途切れたら数え直す。開始は 1 つの会議につき 1 回だけ。
- **MTG-008** ［単体］ 会議が検出されなくなってから 20 秒たったら「会議の終了」とする。20 秒以内に戻れば、続いているものとして扱う。
- **MTG-009** ［単体］ ブラウザの会議は、始まったあとで別のタブに切り替えても、その会議を始めたブラウザがマイクを使っている間は続いているとみなす（別のブラウザがマイクを使っていても、続きにはしない）。デスクトップアプリの会議は、そのアプリがマイクを使っている間だけ続いているとみなす（ほかのアプリがマイクを使っていても続きにはしない）。
- **MTG-010** ［単体・結合］ 会議が続いている間に別の会議が検出されても、新しい会議の開始にはしない。会議が終わって 20 秒たたないうちに別のアプリの会議が始まったとき（4 秒続けて検出されたとき）は、前の会議の録音を止めて、新しいノートで録音を始める。前の録音の文字起こしの仕上げが終わってから、次の録音を始める（仕上げ中でも、次の会議の録音を取りこぼさない）。同じアプリの会議がまた検出されたときは、前の会議の続きとして扱う。
- **MTG-011** ［単体・結合・E2E］ 会議の開始を検出し、設定の「会議の自動検出」がオンで、録音していなければ、ノートを「<会議の名前> <月>/<日> <時>:<分>」（例「Google Meet 11/20 15:04」）のタイトルで作り、録音と文字起こしを始め、ポップアップで知らせる。作ったノートは、メインウィンドウの一覧の先頭にすぐ加わる。
- **MTG-012** ［結合・E2E］ 設定の「会議の自動検出」がオフのときは、会議を検出しても何もしない（ノートを作らず、ポップアップも出さない）。
- **MTG-013** ［結合］ すでに録音中（手動の録音を含む。仕上げ中も含む）に会議の開始を検出したときは、何もせず、いまの録音を続ける。
- **MTG-014** ［単体・結合］ 会議の開始を検出したとき OpenAI の API キーが未設定なら、ノートを作らず、ポップアップで「OpenAI の API キーが設定されていないため、自動で録音できませんでした」と知らせる。
- **MTG-015** ［結合］ ノートを作ったあとで録音を始められなかったとき（マイクがない、など）は、ポップアップで理由を知らせ、作った空のノートは消す（メインウィンドウの一覧にも加えない）。
- **MTG-016** ［単体・結合・E2E］ 会議の終了を検出したとき、自動で始めた録音が続いていれば、ポップアップに「仕上げ中」を表示して録音を止め、残りの文字起こしが終わったらポップアップに「停止」を表示する。
- **MTG-017** ［結合］ 手動で始めた録音は、会議が終わっても止めない。自動で始めた録音を利用者が先に止めていた場合、会議が終わっても何もしない。
- **MTG-018** ［結合］ 会議の途中で設定の「会議の自動検出」をオフにしても、自動で始めて続いている録音は、会議の終了で止まる。
- **MTG-019** ［結合］ 設定の「会議の自動検出」をオフからオンにした時点（設定画面での保存、またはトレイのメニュー）で会議中なら、その会議の録音を始める。自動で始めた録音を利用者が止めたあと、または手動の録音を止めたあとは、同じ会議が続いていても録音を始め直さない（録音を始めるのは、会議の開始を検出したときと、オフからオンに変えたときだけ）。
- **MTG-020** ［結合］ マイクを使っているアプリは、Windows が記録しているマイクの使用状況（アプリごとの使用開始・終了の時刻）から読み取る。使用を開始していて、まだ終了していないものを「使用中」とする。
- **MTG-021** ［単体］ Windows 以外では、会議を検出しない。
- **MTG-022** ［E2E］ E2E テスト用のビルド（cargo の feature `e2e`）では、実際の検出の代わりに、作業フォルダの `meeting.txt` に書いた会議アプリ（googleMeet・slackHuddle・zoom・teams・discord）の会議中として扱う（ファイルがない・空なら会議中ではない）。配布するビルドには、この差し替えは入らない（SEC-012）。
- **MTG-023** ［手動］ 実際の Google Meet・Slack ハドル・Zoom・Teams・Discord で、会議に入ると数秒後に自動で録音が始まり、抜けると約 20 秒後に止まる。
- **MTG-024** ［E2E］ 会議の検出は、製品と同じ仕組みで動く: デスクトップの会議アプリの名前（zoom.exe・discord.exe など）のプログラムが本物のマイクを使い始めると、Windows のマイクの使用状況の記録から読み取って録音を始め、使い終わると猶予のあとで止める。ブラウザ（Edge）が「Meet - …」の題のページで本物のマイクを使い始めたときも同じ。メインウィンドウを閉じて、トレイにいるときに確かめる。
