# TRN: 文字起こし

取り込んだ音声を発話ごとに区切り、OpenAI で文字にして保存・表示する。

- **TRN-001** ［単体］ 音声は 16kHz・モノラルに変換し、発話のあとに 0.7 秒の無音が続いたところで 1 つの発話として区切る（区切るのは 1.5 秒以上の長さになってから）。区切った発話ごとに OpenAI へ送る。
- **TRN-002** ［単体］ 無音だけの区間、換気扇や BGM のように一定の音が続くだけの区間は、発話とみなさず、OpenAI に送らない。背景の雑音がある中での発話は、発話の部分だけを送る。
- **TRN-003** ［単体］ 声の部分が 0.4 秒に満たない音（咳、クリック音など）は捨てて、送らない。
- **TRN-004** ［単体］ 25 秒を超えて話し続けたときは、そこで区切って送り、続きは次の発話として途切れなくつなぐ。
- **TRN-005** ［単体］ 送る音声には、語頭の欠けを防ぐために発話の前の約 0.3 秒、語尾の後の約 0.2 秒を含める。
- **TRN-006** ［単体・結合］ 発話の開始・終了の時刻は、音声を取り込んだ実際の時刻で決まる。処理が遅れてまとめて処理しても、相手が黙っていて音声が届かない時間（0.5 秒を超える空き）があっても、時刻はずれない。
- **TRN-007** ［単体］ 48kHz や 44.1kHz の入力は 16kHz に変換し、16kHz で表せない高い音は取り除く（別の音として混ざらない）。複数チャンネルの入力は平均して 1 チャンネルにする。
- **TRN-008** ［単体・結合］ OpenAI へは `POST /audio/transcriptions` に、16kHz・16bit・モノラルの WAV（ファイル名 audio.wav）、設定のモデル、`response_format=json` を送る。認証は `Authorization: Bearer <キー>`。
- **TRN-009** ［結合］ 設定の言語（ja・en など）を `language` として送る。「自動判定」（auto）のときは `language` を送らない。
- **TRN-010** ［単体・結合］ 同じ音源の直前までの文字起こしの末尾 200 文字を、表記をそろえる手がかり（`prompt`）として次の発話と一緒に送る。最初の発話では送らない。
- **TRN-011** ［単体］ 自分（マイク）と相手（PC の音声）は別々に文字起こしし、同じ音源の発話は話した順に処理する。結果は発話の開始時刻の順に並べる（後から届いた結果も、時刻の位置に入る）。
- **TRN-012** ［単体］ 文字起こしの結果が空、記号だけ、または無音に対して出やすい定型文（「ご視聴ありがとうございました」「チャンネル登録よろしくお願いします」「Thank you for watching」など 7 種。記号・空白・大文字小文字の違いは無視して全体が一致するもの）のときは、捨てて保存しない。結果の前後の空白は除く。
- **TRN-013** ［単体・結合］ 文字起こしの一時的な失敗（通信エラー、HTTP 408・429・500 番台）は、1 秒・2 秒・4 秒と間をあけて最大 4 回まで試す。それでも失敗したら「自分（または相手）の発話（時:分:秒〜）を文字起こしできませんでした: 理由」と知らせ、次の発話の文字起こしは続ける。
- **TRN-014** ［単体・結合］ OpenAI が HTTP 401・403 を返したとき（キーの誤りなど）は、再試行せず、文字起こしと録音を止めて、「文字起こしを停止しました。API キーを確認してください（理由）」と 1 回だけ知らせる（自分・相手の音源ごとには知らせない）。以降の発話は送らない。会議の自動検出で始めた録音のときは、ポップアップにも同じ文と「設定を開く」を表示する（POP-006）。
- **TRN-015** ［結合］ 文字起こしの 1 回の送信は 90 秒で、接続は 15 秒で打ち切る（打ち切りは通信エラーとして再試行の対象になる）。
- **TRN-016** ［単体・E2E］ 文字起こしは届くたびに保存し、開いているノートのものならすぐ画面に加える（話してから数秒遅れ）。ほかのノートの発話は表示しない。同じ発話を二重に表示しない。
- **TRN-017** ［結合］ 文字起こしを保存できなかったときは、「文字起こしを保存できませんでした: 理由」と知らせる。
- **TRN-018** ［単体］ 文字起こしは会話の形で表示する。発話ごとに話者（「自分」「相手」）と開始時刻を表示し、同じ話者の発話が 60 秒以内の間隔で続くときは 1 つのまとまりにする。
- **TRN-019** ［E2E］ 新しい発話が届いたとき、一覧の末尾（下から 48px 以内）を見ていれば自動で末尾までスクロールする。上のほうを読んでいるときは、スクロール位置を動かさない。
- **TRN-020** ［単体］ 文字起こしがまだないときは、録音中なら「話し始めると、数秒後にここへ表示されます。」、録音していなければ「録音を開始すると、会話の文字起こしがここに表示されます。」と表示する。
- **TRN-021** ［単体］ 文字起こしのパネルを開閉するボタンに、文字起こしの件数を表示する。停止したあとも、文字起こしはノートに残る。
- **TRN-022** ［結合・手動］ 実際の OpenAI の API と実際のマイク・PC の音声で、話した内容が「自分」「相手」に分かれて数秒遅れで表示される（設定画面で選べるすべての文字起こしのモデルが、アプリの送る音声を受け付けることを、API キーを登録した CI で週に 1 回確かめる）。
