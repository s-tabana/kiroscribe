# TRY: トレイと常駐

タスクトレイへの常駐、ウィンドウを閉じたときの動き、Windows の起動時の自動起動、終了。

- **TRY-001** ［E2E］ メインウィンドウを × で閉じても、アプリは終了せず、ウィンドウが隠れるだけでタスクトレイに残る。会議の検出と録音は続く。
- **TRY-002** ［E2E］ トレイのアイコンを左クリックすると、メインウィンドウを表示して手前に出す（最小化されていれば元に戻す）。
- **TRY-003** ［E2E］ トレイのアイコンを右クリックすると、「Kiroscribe を開く」「録音を停止」「会議を検出したら自動で録音」（チェック付き）「Kiroscribe を終了」のメニューを出す。アイコンに重ねると「Kiroscribe（会議の自動検出）」と表示する。
- **TRY-004** ［結合・E2E］ トレイのメニューの「会議を検出したら自動で録音」を選ぶと、設定の「会議の自動検出」のオン・オフが入れ替わって保存される。設定画面で変えて保存したときは、メニューのチェックもそれに合わせて変わる。設定画面を開いている間にトレイのメニューで切り替えたときは、設定画面の表示も切り替わり（設定画面で書きかけている、ほかの項目はそのまま）、そのあと「設定を保存」を押しても元に戻らない。
- **TRY-005** ［結合・E2E］ 「Kiroscribe を終了」を選ぶと、録音中なら録音を止め、最後の発話の文字起こしが終わるのを待ってから終了する。
- **TRY-006** ［E2E］ すでに起動しているときにもう一度起動すると、2 つ目は起動せず、起動中のメインウィンドウを表示して手前に出す。
- **TRY-007** ［単体・E2E］ ふつうに起動したとき（スタートメニューなど）は、メインウィンドウを表示する。ウィンドウの大きさは幅 1240px・高さ 820px で始まり、幅 860px・高さ 560px より小さくはできない。いちばん小さくしても、画面の部品はウィンドウの左右からはみ出さず、主な操作（新しいノート・検索・タイトル・メモ・録音のボタン、設定とヘルプの画面の閉じるボタン）はすべて見えている。
- **TRY-008** ［E2E］ Windows の起動時に自動で起動したとき（`--autostart` 付き）は、ウィンドウを出さず、タスクトレイに常駐して会議を待つ。
- **TRY-009** ［単体・E2E］ 設定の「Windows の起動時に Kiroscribe を起動する」（最初はオン）をオンにして保存すると Windows の自動起動（利用者ごとの「スタートアップ アプリ」）に、インストールした実行ファイル（パスは引用符で囲む）を `--autostart` 付きで起動するよう登録し、オフにすると解除する。管理者として動いていても、全ユーザー共通の場所には登録しない（以前の版が全ユーザー共通の場所に書いた、このアプリを指す登録は、消せるときに消す）。タスクマネージャーの「スタートアップ アプリ」で無効にした設定は変えない。起動時にも、設定に合わせて登録をそろえる。登録するのはリリース用のビルドだけ（開発用のビルドは登録しない。E2E テスト用のビルドは、作業フォルダの `config.json` の `registerAutostart` で求めたときだけ登録する）。アンインストールすると、登録は消える。
- **TRY-010** ［E2E］ タスクトレイのアイコンを作れない環境でも、アプリは起動する。
- **TRY-011** ［単体・結合］ トレイのメニューの「録音を停止」を選ぶと、録音中のノートの録音を止める（手動で始めた録音も、自動で始めた録音も。メインウィンドウの「停止」と同じ）。ポップアップがその録音を知らせていれば、停止の表示（POP-005）に変える。「録音を停止」は、録音中と一時停止中だけ選べる。
