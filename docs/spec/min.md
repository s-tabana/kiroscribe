# MIN: 議事録

メモと文字起こしから AI（Claude）が議事録を作る。表示・編集・作り直し。

- **MIN-001** ［単体］ 「議事録を作成」のボタンは、議事録がまだなく、メモか文字起こしのどちらかがあるノートにだけ表示する。
- **MIN-002** ［単体］ メモも文字起こしもないノートで議事録の作成を始めると、「メモも文字起こしもないため、議事録を作れません。メモを書くか録音してから試してください」のエラーになる。
- **MIN-003** ［単体・結合］ Anthropic の API キーが未設定だと作成は始まらず、「API キーが設定されていません（Anthropic）。設定画面から入力してください」と知らせる（「設定を開く」ボタン付き）。表示は自分のメモのまま。
- **MIN-004** ［単体・E2E］ 作成中は、まず「メモと文字起こしを読んでいます…」と表示し、文章が届き始めたら「議事録を作成しています…」とともに、届いた分から順に表示する。先頭のタイトル行（「# タイトル」）は表示しない。
- **MIN-005** ［単体・結合・E2E］ 作成中に「中止」を押すと作成が止まる。エラーの知らせは出さず、議事録は保存されない。議事録がまだなかったノートは、自分のメモの表示に戻る。中止は、押してすぐに効く（AI から次の文章が届くのを待たない。応答が始まるのを待っているあいだや、一時的な失敗のあとの再試行を待っているあいだでも止まる）。
- **MIN-006** ［単体・結合］ 作成が終わると、先頭の「# タイトル」の行を除いた本文を議事録として保存する。ノートのタイトルが空ならそのタイトルを付け、すでにタイトルがあれば変えない。
- **MIN-007** ［結合］ AI の応答に本文がなかったときは、「議事録を作成できませんでした（応答が空でした）。もう一度お試しください」のエラーにし、保存しない。
- **MIN-008** ［単体］ 同じノートの議事録を作成している間にもう一度作成を始めると、「このノートの議事録を作成中です」のエラーになる。別のノートの作成や、AI チャットとは同時に進められる。作成が終わる（または失敗・中止する）と、また始められる。
- **MIN-009** ［単体］ 議事録があるノートで「作り直す」を押すと、確認のダイアログ（「議事録を作り直しますか？ 今の議事録（手で直した部分も含む）は新しい内容に置き換わります。」）を出す。OK なら作り直して置き換え、取り消したら何も変えない。作り直すときも、区切りのあるノートは回ごとの節に分ける（MIN-021）。
- **MIN-010** ［単体］ 「編集」を押すと議事録を文章として直せる。入力は 0.5 秒後に自動で保存し、「編集を終える」を押すとすぐ保存して整った表示に戻る。議事録を空（空白だけを含む）にして保存すると「議事録なし」の状態に戻り、編集を終えると自分のメモの表示になって「議事録を作成」ボタンが出る。
- **MIN-011** ［単体］ 議事録があるノートでは「議事録」と「自分のメモ」を切り替えられ、自分のメモはいつでも見られ、直せる。
- **MIN-012** ［単体］ 議事録の各行（箇条書きと段落）を、自分のメモに由来する行は濃く、AI が補った行は薄く表示する。判定は、記号・空白・全角半角・大文字小文字の違いをならしたうえで、メモのどれかの行と (a) 4 文字以上の一方がもう一方に含まれる、または (b) 2 文字ずつの重なり（Dice 係数）が 0.5 以上、なら「メモ由来」とする。見出しと 2 文字未満の行は色分けしない。凡例（「濃い文字＝あなたのメモ由来」「薄い文字＝AI が補足」）を表示する。
- **MIN-013** ［単体］ AI には、決まった指示文と、会議の情報（タイトル〔空なら「（未設定）」〕、日時、自分のメモ〔空なら「（なし）」〕、文字起こし〔「[15:04] 相手: 〜」の形。発話のある回が 2 つ以上あれば、各回の前に「--- 2回目の録音（14:30〜） ---」の行を入れる。なければ「（なし）」〕）を送る。設定で自分の呼び名を付けていれば、文字起こしの「自分」を「自分（呼び名）」にする。
- **MIN-014** ［結合］ Anthropic へは `POST /messages` に、設定の Claude のモデル、ストリーミング、キャッシュの指定を付けた指示文、effort（議事録は medium）、出力の上限（議事録は 64,000 トークン）を送る。認証は `x-api-key: <キー>`、`anthropic-version` を付ける。1 回の呼び出しは 600 秒で打ち切る。
- **MIN-015** ［単体・結合］ AI が内容を理由に応答を控えたとき、対応するモデル（claude-fable-5-2・claude-fable-5-1・claude-opus-5-5・claude-opus-5・claude-sonnet-5-5）では別のモデルが続きを書く（文章は途中からそのまま続く）。それ以外のモデル（claude-haiku-5-5 など）ではこの仕組みを使わない。最後まで控えられたときは、「Claude がこの内容への回答を控えました。メモや文字起こしの内容を確認して、もう一度お試しください」のエラーになる。
- **MIN-016** ［結合］ 文章が 1 文字も届く前の一時的な失敗（通信エラー、HTTP 408・429・500 番台、過負荷）は、1 秒・2 秒・4 秒と間をあけて最大 4 回まで試す。文章が届き始めたあとの失敗は、再試行せずエラーにする（途中の文章が二重にならないように）。
- **MIN-017** ［単体・結合］ 作成が途中で失敗したときは、何も保存せず、理由を知らせる。すでにあった議事録はそのまま残る。
- **MIN-018** ［単体・E2E］ 会議が終わったあとのポップアップで「議事録を作成」を押すと、メインウィンドウでそのノートが開き、議事録の作成が自動で始まる。
- **MIN-019** ［単体・E2E］ 議事録の作成中に別のノートへ移っても、作成は裏で続き、終わると保存される。作成中に元のノートへ戻ると、それまでに届いた文章とともに作成中の表示（MIN-004）になり、終わると完成した議事録に切り替わる。作成が終わってから戻ったときは、完成した議事録を表示する。
- **MIN-020** ［結合・手動］ 実際の Anthropic の API で、メモと文字起こしから議事録が少しずつ表示され、保存される（アプリと同じプロンプトで、題名と本文に分けられる議事録が返ることを、API キーを登録した CI で週に 1 回確かめる）。
- **MIN-021** ［単体・結合］ 発話のある回（TRN-023）が 2 つ以上あるノートでは、議事録を回ごとの節に分けて作る（作成も「作り直す」も）。AI には、回の数と、回ごとに別の会議のこともあるので内容を混ぜないことを伝え、「## 1回目の録音（14:00〜）」の形の見出し（1 回目の時刻は、最初の発話の時刻）で回ごとに節を立て、それぞれの回の内容をその節の中にまとめるよう指示する。発話のある回が 1 つだけのノート（区切りのない以前のノートを含む）は、今までどおりに作る。
