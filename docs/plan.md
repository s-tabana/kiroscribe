# 開発の計画

会議の相棒を、3 つの段階に分けて作ります。段階ごとに next で開発し、段階が終わったら main に取り込んでリリースします。仕様は[予定の仕様](spec/planned/)（[会議の相棒](spec/planned/cmp.md)・[資料の索引](spec/planned/idx.md)・[サービスの接続](spec/planned/con.md)）にあります。

## 進め方

- 各 PR は、実装する項目を `docs/spec/planned/` から `docs/spec/` の同じ名前のファイルに移し、テストと一緒に入れます（ID は変えません）。
- 種類に「手動」がある項目を移す PR は、[リリース前の実機チェックリスト](release-checklist.md)にも手順を足します。
- 移す項目に関わる未決の点は、その PR を始める前に決めます（「未決の点と決める時期」）。

## 段階1: 指定したフォルダと過去のノート

区切りは、録音中に、指定したフォルダと過去のノートの資料が、文字起こしの発言の間に出ることです。新しいキーやログインは要りません（AI には、いまの Anthropic の API キーを使います）。

| PR | 中身 | 移す項目 | 合わせて直す既存の項目 |
| --- | --- | --- | --- |
| 1-1 | フォルダの索引（ファイルの読み取り、索引の作成と見張り、検索と抜粋、設定の「探すフォルダ」） | IDX-001〜IDX-015 | DAT-001、SET-001、IPC-001〜IPC-003 |
| 1-2 | 相棒の本体（きっかけ、判定と選択、出しすぎないための条件、結果の保存）と、過去のノートの索引 | CMP-001〜CMP-019、CMP-025、CMP-026、CMP-038、CMP-040〜CMP-044、IDX-017〜IDX-019 | SET-001、SET-005、SEC-005、SEC-011、NOTE-015、IPC-001〜IPC-005 |
| 1-3 | 画面（バッジ、詳細、録音のバー、設定の「会議の相棒」の欄） | CMP-021〜CMP-024、CMP-027〜CMP-037、CMP-045、IDX-016 | IPC-001〜IPC-005 |
| 1-4 | 仕上げ（実際の API での確認、利用者向けの文書） | CMP-020、CMP-039 | README の「データとプライバシー」、guide.md、CHANGELOG.md |

## 段階2: ブラウザの履歴とブックマーク

区切りは、Chrome と Edge で見たことのあるページも、相棒の資料として出ることです。履歴は PC の中で読み、ページの本文は読みません（未決 5 の推奨案）。

| PR | 中身 | 移す項目 | 合わせて直す既存の項目 |
| --- | --- | --- | --- |
| 2-1 | 履歴とブックマークの索引（Chrome・Edge のすべてのプロファイル）と、設定のオンとオフ | IDX-020〜IDX-025 | SET-001、README の「データとプライバシー」 |
| 2-2 | ブラウザの資料の開き方 | IDX-026 | SEC-008、guide.md、CHANGELOG.md |

## 段階3: Google Drive と Slack

区切りは、「接続」で一度ログインしたサービスの中も、相棒が探すことです。最初に Google Drive、次に Slack をつなぎます。3-3 を始める前に、Slack アプリの設定で、戻り先のアドレス（ポートを固定するか）を確かめます。

| PR | 中身 | 移す項目 | 合わせて直す既存の項目 |
| --- | --- | --- | --- |
| 3-0 | 準備（オーナーの作業。コードの変更なし）。Google Cloud でデスクトップ用の OAuth クライアントを作り、Slack アプリを作って PKCE を有効にする | なし | なし |
| 3-1 | 接続の共通部分（戻り先の受け口、PKCE、トークンの保存と取り消し、設定の接続の欄）と、Google Drive の接続 | CON-001〜CON-011 | SEC-004、SEC-005、IPC-001〜IPC-005、development.md（OAuth クライアントの ID の置き場所） |
| 3-2 | Google Drive の検索 | CON-012〜CON-014、CON-018、CON-019 | なし |
| 3-3 | Slack の接続と検索 | CON-015〜CON-017 | SEC-005 |
| 3-4 | 仕上げ（実際のサービスでの確認、利用者向けの文書） | CON-020 | README の「データとプライバシー」、guide.md、CHANGELOG.md |
