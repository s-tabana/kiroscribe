# IDX: 資料の索引

会議の相棒（[cmp.md](cmp.md)）が探す、PC の中の資料と、その索引。指定したフォルダの索引の作り方・更新・探し方は、仕様一覧の [idx.md](../idx.md) にある。段階1 は指定したフォルダと Kiroscribe の過去のノート、段階2 はブラウザの履歴とブックマーク。この節の未決の点は、末尾の「未決の点」にある。

## 指定したフォルダ（段階1）

- **IDX-031** ［単体］ ローカルのフォルダの資料は、探し先の名前を「ローカルのフォルダ」、場所をファイルのパスにする。コピーのボタンは「パスをコピー」（ファイルのパスを書き込む）、開くボタンは「ファイルを開く」（既定のアプリで開く。CMP-032）にする。

## 索引の作り方と更新

仕様一覧の [idx.md](../idx.md) の IDX-011（「索引を作り直す」）に、段階2 で「ブラウザの履歴とブックマークは、IDX-023 の条件を満たすときだけ読み直す」を足す。

## Kiroscribe の過去のノート（段階1）

- **IDX-032** ［単体］ 過去のノートの資料は、探し先の名前を「Kiroscribe の過去のノート」、場所を「ノート「<題名>」 <作成日時>」（作成日時は NOTE-012 の形）にする。コピーのボタンは「要点をコピー」（該当する箇所と「（ノート「<題名>」 <作成日時>）」を書き込む）、開くボタンは「ノートを開く」（そのノートを開く。録音は止めない）にする。

## ブラウザの履歴とブックマーク（段階2）

- **IDX-020** ［単体・E2E］ 設定の「ブラウザの履歴とブックマーク（Chrome・Edge）」がオンなら、選んだプロファイル（IDX-029）の履歴とブックマークから探す。初期値はオフ。欄には、ページの題名と送るための URL（クエリとフラグメントを除いたもの。CMP-043）が選択のときに Anthropic へ送られ、ブックマークのフォルダの名前は送られないことを表示する。オンとオフとプロファイルの選択（IDX-029）は、ほかの設定と同じく「設定を保存」で保存する（SET-002）。保存せずに閉じたときはオフのままにし、履歴とブックマークは読まない。読み始める時点は IDX-023 で決める。
- **IDX-029** ［単体・E2E］ ブラウザの欄に、見つけた Chrome と Edge のプロファイル（ブラウザの名前とプロファイルの表示名）を一覧にし、探すプロファイルをチェックで選べる。初期値は、どのプロファイルも選ばない。
- **IDX-021** ［単体・結合］ 履歴は、ブラウザのファイル（Chrome は `%LOCALAPPDATA%\Google\Chrome\User Data\<プロファイル>\History`、Edge は `%LOCALAPPDATA%\Microsoft\Edge\User Data\<プロファイル>\History`）を、付随するファイルと一緒に一時フォルダへ写してから読み、読み終えたら写しを消す。ブラウザが起動したままでも読め、ブラウザのファイルは変えない。ブックマークは、同じプロファイルの `Bookmarks` を読む。
- **IDX-022** ［単体］ 索引に入れるのは、`http://`・`https://` のページの題名・URL・最後に見た日時・見た回数と、ブックマークの名前・URL・フォルダの名前だけ。URL のフラグメント（「#」から後ろ）は除いて入れる。直近の 180 日に見ていない履歴と、検索サイトの結果のページは入れない。ユーザー名やパスワードを含む URL と、クエリかフラグメントに認証の値の名前（`code`・`token`・`access_token`・`id_token`・`refresh_token`・`auth`・`key`・`api_key`・`apikey`・`password`・`passwd`・`pwd`・`secret`・`client_secret`・`session`・`sessionid`・`sid`・`sig`・`signature`・`X-Amz-Credential`・`X-Amz-Signature`・`X-Goog-Credential`・`X-Goog-Signature`。大文字と小文字は区別しない）を含む URL も入れない。
- **IDX-023** ［単体・結合］ 履歴とブックマークを読むのは、保存した設定で、相棒（CMP-036）とブラウザ（IDX-020）の両方がオンで、プロファイルを 1 つ以上選んでいる（IDX-029）ときだけ。この条件を満たすあいだ、次の時点で読み直す: 条件を満たしたままアプリを起動した時点、設定の保存で条件を満たした時点（相棒をオンにした、ブラウザをオンにした、初めてプロファイルを選んだ）、プロファイルの選択を足して保存した時点、録音を始めた時点、録音中の 10 分ごと、「索引を作り直す」を押した時点（IDX-011）。条件を満たさないときは、どの時点でも読まない。相棒がオフなら、アプリを起動しても、ブラウザやプロファイルの設定を変えても、録音を始めても、録音中の 10 分ごとの時点でも、「索引を作り直す」でも読まない。チェックを切り替えた時点では読まず、設定を保存した時点から読む（SET-002）。読み直しは裏で進め、画面の操作と録音を止めない。
- **IDX-024** ［単体］ ブラウザの資料の抜粋は、題名と URL（ブックマークならフォルダの名前も）にする。ページの本文は読まない。選択（CMP-013）で Anthropic へ送る抜粋は、題名と、クエリとフラグメントを除いた URL（CMP-043）だけにし、ブックマークのフォルダの名前は送らない。
- **IDX-025** ［単体］ Chrome・Edge が入っていないときや、ファイルを読めないときは、そのブラウザを飛ばし、設定の欄に理由を表示する。相棒のほかの探し先は動く。
- **IDX-030** ［単体・結合］ ブラウザをオフにすると、履歴とブックマークの読み直しを止め、索引からブラウザの資料をすべて消す。プロファイルの選択を外したときは、そのプロファイルの資料を消す。
- **IDX-033** ［単体］ ブラウザの資料は、探し先の名前を「ブラウザ（<ホスト名>）」、場所をページの URL にする。コピーのボタンは「URL をコピー」（URL を書き込む）にする。
- **IDX-026** ［単体・結合］ ブラウザの資料の開くボタンは「ブラウザで開く」にし、いまも索引にある URL だけを既定のブラウザで開く。`http://` の URL も開く（SEC-008 の条件のうち、`https://` に限る条件だけを外し、ほかの条件はそのまま当てはめる）。ほかの条件に当たる URL は開かず、「このリンクは開けません」と表示する。索引にない URL（ブラウザをオフにした、プロファイルの選択を外した、直近の 180 日に見ていないため索引から外れたなど）は開かず、「このページは、ブラウザの履歴とブックマークの索引にありません」と表示する。バッジと詳細は、保存した結果のまま表示する。

## 未決の点

### 未決 5: ブラウザで見たページの本文を読むか

決めること: 段階2 で、見つけたページの本文を取りに行くか。
本文がないと、該当する箇所は題名と URL だけになる。
推奨案で書いている項目: IDX-024。

| 案 | 変わること |
| --- | --- |
| A. 読まない。題名・URL・ブックマークのフォルダだけで探す（推奨） | 外部への接続は増えない（SEC-005 は変わらない）。題名に出ない内容では見つからない |
| B. 候補のページの本文を、その場で取りに行く | 中身で選べる。任意のサイトへ接続することになり、ログインが要る社内のページは読めない |

### 未決 6: http:// のページを開くか

決めること: 履歴とブックマークにある `http://` のページを、「ブラウザで開く」で開くか。
社内の Wiki などは `http://` のことがあり、いまの約束（SEC-008）では開けない。
推奨案で書いている項目: IDX-026（B にしたときは、`http://` の URL を開かず、「http:// のページは開けません。『URL をコピー』でブラウザに貼ってください」と表示する）。

| 案 | 変わること |
| --- | --- |
| A. 履歴とブックマークにある URL に限り、`http://` も開く（推奨） | 社内のページもすぐ開ける。開く URL は利用者のブラウザが以前に開いたものだけに限る。PR 2-2 で SEC-008 に例外を足す |
| B. `https://` だけを開き、`http://` はコピーだけにする | SEC-008 は変わらない。`http://` のページは、コピーしてブラウザに貼る手間がある |
